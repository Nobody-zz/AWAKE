## 三 为什么"启动服务看日志"这条验不了

试过：直接在游戏目录里跑 `MarcusAwakeRuntimeService.exe`，得到

```
descriptor_read_failed     退出码 4
```

读代码对上：`RuntimeServiceHost.RunAsync():116` 第一件事就是 `ReadBootstrapAsync(Console.OpenStandardInput())`
—— **服务必须由游戏端从 stdin 喂一帧 descriptor 才会往下走**，而 `CreateEmbedder()` 在 `:118`。
⇒ 这一层**只能由游戏拉起**，离线没法单独点着。

（顺带一条有用的事实：`Program.Main` 里 `ServiceArguments.Validate` 要求 **参数个数为 0**，多一个就 `stdin_bootstrap_only` 退出。）
