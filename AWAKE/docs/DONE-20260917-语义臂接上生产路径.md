## 二 三个不是可选的设计点（都是既有事实逼出来的）

1. **世界书加载早于战役会话**（`ProbeExtension` 的 `WorldbookRuntime.EnsureCreated()`），
   而 RAG 数据面要一个**战役内**的 session lease（向量按 `campaign_guid`/`timeline_id` 分行存）。
   ⇒ 挂载点不能"世界书一发布就挂"，只能**先登记、后等 host**；`CampaignSessionReady` 上再补一次。
2. **入库是 28 批 × 16 条**（448 条，每条都要编码）⇒ **绝不能放在加载或对话热路径**，一律后台线程。
3. **换战役会话必须重新入库** —— 新档里那些 `campaign/timeline` 分行的向量**不存在**。
   ⇒ 幂等键是「**语料指纹 ＋ 会话**」，不是"挂过一次就永远算数"。
   （实测过：拿"挂过没挂过"当键，换档后语义臂会**静默空转**。）

**失败一律静默回落**（没有 host / 没有 RAG / 没模型 / 入库超时 / 编不出向量）：
不抛、不重试到死、不留半截状态 —— 这是本项目已写下的口径：**语义是加分项，不是替代项**。

**真机判读**：`awk`／grep 日志里的 `awake_semantic_arm`：
- `status=attached entries=<入库数> of=<包内总条数> fingerprint=… session=…` ⇒ **通了**
  （写入时实例值 `entries=448 of=448` —— **当时**包 448 条。当天 18:39 v13f 上线后包已 **451 条**，
  详见本文件 §五 上面那条"未通电"与 `HANDOFF-20260917-语义臂真机-主干侧提示词.md`：
  **真机读到 `of=451` 是对的**，不是丢条目。）
- `status=host_unavailable` ⇒ 这一轮没等到 host（等 `CampaignSessionReady` 的那一次）
- `status=ingest_failed code=… entries=… fingerprint=…` ⇒ 服务侧那半有问题（多半是模型没就位）
- `status=already_attached key=…` ⇒ 幂等生效，属正常
- 另有 `skip`／`no_rag`／`retry_requested`／`not_campaign`／`error` 几个 `status`，见 `AwakeSemanticArmBootstrap.cs`
