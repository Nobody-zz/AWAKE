# 角色卡盲评记录模板

> 每位评审者各使用一份独立副本。第一阶段只填匿名样本；评审者锁定并签署判断后，才可打开第二阶段证据账。至少一位评审者必须未参与该卡写作；若触发规范中的升级条件，第二位评审者另填一份，不得先看第一人的结论。原始姓名/heroId 到匿名 ID 的映射应由独立保管人另存，不得附在盲评包中。若无法保证匿名，记录为 `BLINDING_FAILED`，本轮不作人格区分结论。卡片的匿名“声明范围”应在第一阶段提供；它用于限定评审边界，不提供来源/身份，不得被误读为作者要求模型必须填满该范围。

## B. 第一阶段：不知道身份和来源

每个样本独立填写；判断引用回答原文，不猜角色姓名、文化或卡作者意图。

遇到“事实不足/unknown”情境，必须同时对照该条最终 prompt 中实际给出的检索知识、记忆和角色资料。玩家问题本身不能证明模型另有消息来源；“我听说/刚查过/某家族或部族所为/某地有人活动”等具体说法若未出现在输入中，应记录为待核越界，不能以“可能是真的”放过。相同越界若跨人物出现，优先反馈共用提示词/运行时层，不要求角色卡作者补造设定。

### 跨卡比较（仅在声明范围有实质重叠时填写）

如果没有声明范围重叠的可比卡，填写 `NOT_APPLICABLE_WITHIN_DECLARED_SCOPE` 并记录检索范围；不得为完成表格而扩大目标卡或比较卡的内容。若存在重叠，至少对照一组共同情境；可比卡不足时比较所有可用对象并标注样本限制。

| 情境 | 对照卡 | 选择是否可互换 | 理由是否可互换 | 是否仅替换名词/槽位 | 两条原文证据 | 判定：差异 / 同质 / 不确定 |
|---|---|---|---|---|---|---|
|  |  |  |  |  |  |  |

只句型相同但选择、理由或适用条件不同：记为“句式线索”，**不单独判同质化**。若判断同质，须引用至少两种情境下的实际回答，并说明重复的是选择/理由还是表达骨架。
