# 角色卡制作规范盲审夹具包

> 这是给独立评审者的材料。不要附带作者答案钥匙、红测日志或作者口头解释。评审者只按制作规范和本包材料作答，并在锁定全部判断后再查看规范要求的第二阶段证据。

## 使用说明

- 每位评审者单独填写一份 [`PERSONA-PRODUCTION-SPEC-REVIEW-FORM-20260925.md`](PERSONA-PRODUCTION-SPEC-REVIEW-FORM-20260925.md)；两人不得互看结论。不要使用面向真实角色回答的通用盲评表替代本表。
- 夹具内的姓名、地点和数值均为虚构占位，不映射到游戏人物或既有角色卡。
- 逐条判定夹具所测问题、规范第八节的生产结论、是否允许 `approved` 及技术门状态；分别引用触发规则，不要只写“像 AI”或只报总分。
- C 的 DSL / prompt 证据视为本夹具提供的真实链路报告；实际规范验收时也应核对附件哈希和原始报告。

## 夹具 A：换槽后决策仍相同

三张匿名卡 A、B、C 的证据账都没有证明人物采取下列策略。每张卡有两条运行时素材：

| 情境 | 卡 A | 卡 B | 卡 C |
|---|---|---|---|
| 货车失踪，要求立即补发 | “先核损，再等货源查清后决定是否补运，免得把未知损失继续扩大。” | “先查账目，再等货物去向确认后决定是否重发，免得扩大不明损失。” | “先点清缺口，再等原因查明后决定是否补货，不能让未知损失继续增加。” |
| 外使要求调兵，须当场答复 | “先核军粮，再等代价明确后承诺，不能让士兵承担未知风险。” | “先看补给，再等损失算清后答复，不能把不明代价压给军队。” | “先查仓储，再等成本明白后决定，不能拿兵士去赌未知风险。” |

## 夹具 B：地点关联被扩写成税权

来源记录只证明“人物的家族与城堡 X 有关系”。没有任命、治理、财政、征税、收成或人物亲自处理税务的记录。候选运行时行为为：

> 她每年派人征收城堡 X 的税粮，并按收成决定交付多少。

作者说明称：“她家族在那里，所以这件事很合理。”

## 夹具 C：定义存在，最终载荷缺失

作者记录中的 Claim `C1` 标记为 `runtime_required=true`，原文为 `“公开承诺只在供应账目核实后作出。”`。

链路报告给出：

- 物化 definition 含完整 C1；
- 真实 DSL 生成日志为 `fallback=False`、`trimmed=True`；
- DSL 的所有 `DATA_CN` 都不含 C1；
- 使用生产 C# 模板渲染后的最终 prompt 也不含 C1。

## 夹具 D：简单但有据的有限范围卡

来源仅证明：角色 A 是城堡 X 的守卫队长；公开记录写明她遇到陌生人时会先询问来意。没有资料支持其野心、私人恐惧、家族政治、战场经历或更复杂的动机。

作者明确把用途/刻画范围限定为“守卫队长的身份 + 面对陌生来客时先问来意”。运行时字段只写身份/职位事实，并保留这一有来源的克制倾向。`selfClaimRules`、`realSelfBehaviors`、`selfClaimExamples` 均留空，没有文化标签，也没有长篇自传。夹具未提供物化、DSL、最终 prompt 或独立盲评结果；评审须判断此卡是否有资格在该窄范围通过，以及哪些证据仍缺，不能把缺失的技术证据当成通过，也不能要求补第二项行为。

## 夹具 E：相同句式，不同选择和理由（负对照）

两张卡都使用“先 X，再 Y”的表达框架。相同情境一：盟友请求出兵。

- 卡 A：来源证明其军队缺粮；回答先核军粮，再拒绝出兵，理由是不能让士兵挨饿。
- 卡 B：来源证明其与盟约有明确出兵义务且粮草充足；回答先核行军期限，再接受有限支援，理由是履约但不拖垮本国防线。

相同情境二：要求立即承诺军需。

- 卡 A：先查存粮，再延后答复，避免损害军中口粮。
- 卡 B：先核盟约期限，再承诺限期供给，避免违约同时保留守备。

## 夹具 F：窄范围许可不能掩盖超范围主张

来源与夹具 D 相同：只证明守卫队长身份及“陌生来客先问来意”。但作者在 `core` 中另写“野心勃勃、绝不背叛盟友”，并添加 `trait.ambitious`、`trait.loyal`；没有相关来源、已批准补写或运行时证据。

评审须判断：D 的窄范围可通过资格不能为 F 的额外主张背书；F 必须删除/补证越界内容或缩小范围后重审。不得把“人物本来可能如此”当证据。
