# DECISION · 2026-09-16 · 旧代检索链路随世界书标准换代作废

## 甲方原话（一字不改）

> 1问题是当时世界书还是沿用的AF世界书标准，与先行世界知识体系标准完全不同了。所以现在没什么用了。

## 一、口径

1. **`docs/AI-Retrieval-Memory-Principles-20260815.md` §一.2 的"四层召回"**
   （规则层 → 语义层 Marcus RAG → 倒排回退 → 无命中不注入）
   **是面向 AF 世界书标准写的，不是现行世界知识体系的依据。**
   ⇒ **不得再拿它论证"语义层该放哪"。**（我 22:4x 就是这么用的，已按本条改判。）

2. **旧代检索链路作废、不接**：`KnowledgeService` → `_host.Rag`（IPC）＋ `_localIndex`（倒排）。
   它当初的定位记在 `docs/AF-BORROWED-IDEAS-LOG.md:16`：
   「世界书检索管线（关键词/短句/语义原型/条件变体/注入上限/命中率）…**计划：`KnowledgeService` 升级**」，
   内容源标注为"自有 schema、**Marcus RAG、四档世界书为唯一内容源**"。

3. **现行链路是 `WorldKnowledgeQueryService`**（`WorldbookRuntime.Knowledge`，模组进程内，
   读 worldbook-studio 编译的 `runtime.json`（**当时 458 条**；⚠️ 包换过两回，**现已 451 条**
   —— 448 那版是 09-17 早、v13f 上线后是 451；别拿 458 去核对今天的包），**每轮对话必经**（`NpcDialogueService.cs:1080`，
   09-17 晚核过、行号仍准）。
   **语义接在这一条上。** 逐环出处见 `docs/AWAKE-KNOWLEDGE-GATE-20260916.md` §二。

4. ⚠️ **据此重读** `docs/AWAKE-HalfDone-Inventory-20260816.md:26` 的
   「知识检索：**运行时语料 `awake_knowledge.json` 缺失；内容包语料未接入**」——
   应读作**它随标准换代不再需要那份语料**，而不是"缺一份待补的语料"。
