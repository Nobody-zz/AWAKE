## 2. 逐条验尸（数据）

### 验尸 A · "问答框残留 72%" 是读错了判定单位

- 报告一原文：样本含问答框 148/206（72%），暗示门禁失效。
- **但 E5 的判定单位是"单卡内占比 ≥50%"，不是"跨卡样本汇总"。** 逐卡细分：

| 卡级形态 | 卡数 |
|---|---|
| 卡内 ≥50% → 门禁**已判 FAIL** | **64** |
| 卡内 0<占比<50% → 门禁**放行**（真漏网） | **4** |
| 卡内 0% → 干净 | **8** |

- **结论**：那 148 条残留，**绝大多数集中在已被 E5 判 FAIL 的卡里**——门禁已经判了它们。报告一"用门禁正常工作产生的数据，去证明门禁失效"，是**逻辑倒置**。
- 真实漏网面是 **4 张**（卡拉多格、埃卡朗、拔该、阿卡尔——都是 1/3 含框）。攻击方向（"半数以下就能溜"）**成立**，但**数字被夸大了 16 倍**。

### 验尸 B · "61 张被判 FAIL" ≠ "规范禁掉了无底线人格"

- 报告一原文：E2b 同时命中者仅 15/76，"其余 61 张被判 FAIL"，引用为"规范禁止了没有底线的人"。
- 归因检查这 61 张：

| 归因 | 卡数 |
|---|---|
| 含绝对词（永远/绝不/总是…，即 M3 明令禁止的写法） | **26** |
| 含"底线语义"的更宽写法（不退/不许/休想/免谈/不惜命…但不在 11 词表内） | **10** |

- **结论**：这 61 张的绝大多数**不是"没有底线的角色"**，而是"**有底线、但没用到词表里那 11 个词**"。它们是"词表不匹配"的受害者，**不是"人格被排斥"的受害者**。
- E2b 是 AND 判定、原理上排斥"不可谈判/无底线"人格——**这个逻辑漏洞真实存在**；但报告一拿这 61 张当例证是**证据错配**。真正该被举证的受害者（疯的、痴的、铁板一块的角色），**在现有 76 卡里报告一一例都没找出来**。

### 验尸 C · 合成卡 "无痕混入" —— 方向说反了

- 报告一原文：合成卡与真实卡相似度 0.000，"连差异度这把尺子都挑不出它"，能"无痕混进真实卡群"。
- 实测分布：

| | 值 |
|---|---|
| 真实卡**两两** Jaccard 平均 | **0.0159**（中位 0.0144，最大 0.1757） |
| 合成卡 vs 真实卡 平均 | **0.0000**（最高 0.0017） |
| 合成卡落在真实分布的百分位 | **第 1%**（最离群端） |

- **结论**：合成卡**比任何一张真实卡都离群**。它在"用词"维度上是**最容易被挑出来的那个**，不是"无痕"。
- 正确表述只能是："**门禁不检查这个维度，所以 0.000 也不会被拦**"——**"没被拦"不等于"像"**。报告一把"独特"包装成"无痕"，是**论证方向错误**。
- 附带自查：报告一还写"组内平均 0.021"，与本处"两两 0.0159"是**不同口径**（同王国组内 vs 全域两两），报告一未说明口径差异。

### 验尸 D · "跑绿七道门禁" —— 未实测

- 实测**只跑了 E1–E5 的 python 镜像**；schema / affiliations / text / compile / 8 场景 / 物化 **一道未跑**。
- "七道全绿"是**推断**（前四道只查结构与归属，与个性无关），**不是观测**。
- 正确写法："**第五道实测全绿；其余六道未测，按性质推断亦会通过**。"

## 4. 收敛后的结论

**报告一的 10 条攻击，收敛为 3 个母题：**

1. **关键词冒充语义**（E3 / E2b / E5 / M1W）——用词表替代判断，于是可被低成本满足，或用裸单字导致常开。
2. **一套骨架套全体**（M2 三轴 / E2b 的 AND）——把"理性谈判者"的人格模型强加给所有角色。
3. **越界管输出**（M4 / M7 / W9#6）——规范伸手规定了"模型该怎么说话"，而非"给模型什么素材"。

**其中真正该修的，只有 3 条**（其余是无害或固有边界）：

1. **M7 / W9#6 从硬门降为观测**——它测的是模型的输出，不是卡的素材；且会反向迫使素材与角色语言脱钩（此条为**假设**，建议以小样本实测先验证，见验尸 D 教训）。
2. **E3 删掉裸单字**——「但/却/才」不构成条件化信号，属无效判定（数据支撑：47 张仅靠单字过门）。
3. **M6 补一条可执行判据**——把"脱名可辨识"落成可机械核验的指标，这是唯一直接服务"反脸谱"目标的条目，却唯一没有工具。

**不需要动的**：E1 条数上下限（压下限是写手行为，不是规则错）、RT-10 所述门禁天花板（固有边界）、E5 现有形式判定（作为下限拦截是有效的，尽管测不到结构相似）。

## 5. 方法教训（供后续自用）

1. **攻击前先定义靶子**。名词不定义，"反脸谱化"就是一块可以随便糊的墙。
2. **判定单位要对齐判定规则**。"单卡占比"的规则，不可用"跨卡汇总"的数据去否决。
3. **区分"没被拦"与"像"、"测不到"与"不存在"**。这是报告一最贵的一课。
4. **推断必须当场标"待验证"，且排序时按证据强度排，不按"听起来深不深"排**。
5. **红队报告要写"我撤回了什么"**。全中的红队不能信。
