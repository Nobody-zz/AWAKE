砍掉了什么（这是本次修的主因）
1. 说话人立绘槽 200×320 —— 它最大、最重，内容却是空的，重心就是被它抢走的。
2. 此处质感槽 236×110、属性行 ×3、关系行、状态说明行。
3. 在场人物的「身份 / 关系」两行 —— 身份只在对话区顶部显示一次，不必每人重复。
4. 模式键的常驻边框 —— 未选中就是纯文字，只有选中的才有框。
留下来的重心：只有一个「面」（对话区 920×491），只有一个视觉落点（最新一条的 2px 金条），金只出现 4 处。
控件的坐标与尺寸一律没变（关闭 40×40 / 模式 高 35 / 输入框 56 / 结束 100×35 / 发送 110×35），改的是分组、描边与信息量。
