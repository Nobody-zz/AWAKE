# 战帆参考索引

- Schema: awake.war-sails-reference-map.v1
- 来源：C:\Users\26811\Downloads\战帆英文 与 C:\Users\26811\Downloads\战帆中文
- 定位：战帆是卡拉迪亚世界的官方 DLC；本索引是同一世界下的 DLC 参考，不是当前 AWAKE 正典，也不是当前本机游戏对象关系权威。

- 未执行：根据描述文本推断 HeroId → ClanId → KingdomId，也未把新增对象写入默认游戏映射。

文件：

- war-sails-reference-string-map.v1.json：机器可读完整索引。
- war-sails-reference-string-map.v1.csv：内容编辑者可筛选查看的表格。

使用规则：

1. 当前已安装的 Bannerlord XML 优先用于当前运行对象代码和关系绑定；本机未安装战帆时，不能把“本机缺少数据”当成对象冲突。
2. 战帆索引用于识别同一世界下的官方 DLC 对象、补充翻译和提出人工审查候选。
3. 任何候选进入 AWAKE 世界书前，仍必须由开发者决定其正典状态、启用条件和适用内容包；这不是把战帆另建成一个世界。
