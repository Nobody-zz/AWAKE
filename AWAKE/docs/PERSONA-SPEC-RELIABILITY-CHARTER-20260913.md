# 角色卡规范 · 可靠性宪章（红队收敛判据）

- 日期：2026-09-13
- 用途：给「持续红队测试直到规范可靠」这件事一个**可判定的终点**。没有它，红队是无限循环，"直到"永不到达。
- 纪律：本宪章定义**什么叫可靠**，不定义**怎么修**。修法见各版本规范与红队报告。

---

## 0. 为什么必须先把"可靠"钉死

前两轮红队的元教训是**"攻击前先定义靶子"**（`PERSONA-REDTEAM-2` §5.1）。如果"脸谱化"可以随口定义，那么"可靠"同样会变成一块可以随便糊的墙——每修一版都能宣称"这次可靠了"，永远没有终点。

因此，先把"可靠"翻译成**七条可判定的判据**。规范同时满足七条 = 可靠；任一条不满足 = 不可靠，且**指出漏在哪**。

---

## 1. 七条判据

| # | 判据 | 判定方式 | 典型违规 |
|---|---|---|---|
| **R1** | **素材层 / 输出层分离** | 所有硬门的判定对象必须是**卡内素材**；任何以「模型输出」为判定对象的规则只能出观测报告 | W9 第 6 道用 `maxOverlapRatio` 判卡的死活 |
| **R2** | **条款自洽** | 不存在两条条款对同一段文本给出**相反要求**（如 M3 禁的词恰是 E2b 必填的词） | M3 禁「绝不」，E2b 的必填底线词表里恰有「绝不」 |
| **R3** | **判定基础非枚举** | 硬门的判定不得依赖「有限词表命中」；词表只能作辅助信号，判定须落在**结构 / 共现 / 分布**上 | E3 靠裸单字「才/但/却」；E5 靠有限动词族 |
| **R4** | **声明即落地** | 被标为「强制」的条款必须有对应自动化判定；无工具者必须**降级为人工/盲评**并明写，不得假称门禁 | M6 宣称反脸谱验收，却零自动化；M5 宣称处境/视角/语气，门禁只测开头 8 字 |
| **R5** | **允许缺席** | 人格可显式声明 `none`（无底线 / 不可谈判 / 无破例），不得强制单一心理骨架 | E2b 的 AND 判定原理上排斥「不可谈判」人格 |
| **R6** | **机械化边界明示** | 明写哪些维度机械层**不可能**判定（语义空洞、脱名可辨识），并给出**盲评协议**兜底；不得让门禁假装能测 | 合成零个性卡可跑绿第五道门禁 |
| **R7** | **收敛** | 红队套件（`redteam/run-attack-suite.py`）连续两轮**无新增 BREAK**，且历史 BREAK 全部转为 HOLD/EDGE | ——"直到可靠"的停止条件 |

> **关键认识（R3 得出）**：R6 与 R7 决定了这套规范的形态。**反脸谱在语义层面不可机械化**——任何"门禁保证反脸谱"的规范都在撒谎，因而是**不可靠**的。可靠的规范恰恰是**承认这条边界**、把语义判定交给盲评、把机械层降格为"下限拦截"的那一份。

---

## 2. 三档判定（红队套件输出口径）

| 判定 | 含义 | 处置 |
|---|---|---|
| **HOLD** | 攻击失败，规范在这一点上站得住 | 通过 |
| **BREAK** | 攻击成立，规范被击穿 | **必须修**，修完重跑 |
| **EDGE** | 边界——机械化的固有天花板，**不是规范缺陷** | 计入"必须由人工/盲评层兜底"的清单，不要求修 |

> EDGE 不是免罪符：一条攻击若被判 EDGE，**规范必须已在文本里承认该边界并给出兜底路径**；否则它就是 BREAK（因为它在假装能做到）。

---

## 3. 规范的分层结构（v4 起）

```
┌─ 硬门（机械，可判生死） ──────────────── 只判【结构与形式】的下限
│   E1 条数 / E2 三轴声明 / E2b 张力入运行时（窗口共现）/ E4 破例落点
│   E5 结构框占比（替代动词枚举）
│
├─ 观测（机械，出报告不判生死） ────────── 记录事实，供人判断
│   O1 复读自检（原 M7 / W9#6）· O2 处境覆盖 · O3 族属符号重合 · O4 疑似纯台词
│
└─ 认证（人工 / 盲评，唯一能治语义的层）
    Q1 脱名可辨识（遮名能否认出是谁）· Q2 语义密度（去掉名字后还剩什么）
```

- **硬门守下限**：能机械判定的只有"形式是否合规"，它拦得住最粗糙的偷懒，拦不住语义空洞。
- **观测出证据**：把机器能测但测不准的（复读、覆盖、符号）变成**报告**，不变成生死。
- **认证治根本**：反脸谱只能靠"遮住名字还认不认得出"这类**语义判断**，交人工/盲评，并留存记录。

---

## 4. "可靠"的验收动作（每次改规范后跑）

```bash
python tools/persona-workbench/redteam/run-attack-suite.py --spec <版本>
```

- 退出码 0 = 无 BREAK。
- 连续两版退出码 0，且上一版的所有 BREAK 均已转 HOLD/EDGE → **按 R7 判定收敛**。

---

## 5. 边界

- 本宪章只覆盖**表达质量 / 反脸谱 / 扮演自由**三条目标；取证与归属（W1–W8）不在此列。
- "连续两轮无 BREAK"是**必要条件，不是充分条件**：它只证明"现有攻击集打不穿"，不证明"世上无攻击"。红队套件的攻击面须随每次报告扩充——**收敛的是当前武器库，不是真理**。
