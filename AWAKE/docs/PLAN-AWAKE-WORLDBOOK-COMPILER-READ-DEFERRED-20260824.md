# AWAKE 世界书编译端与时间范围读取方案（延期入库）

状态：`deferred`

本文件只保存已经讨论过的方向，不代表当前批次开始实现。当前开发重心是 Worldbook Studio 的 AI 参考资料创作流程；本文件不得被解释为运行时读取器已完成。

## 已确定方向

- 世界书负责开局前历史、静态背景和开局知识基线。
- 游戏状态负责战役中已经实际发生的事实。
- 战役事件、周报和公告负责把后续发生的内容写入动态世界状态。
- 不把世界书中的年份直接映射成游戏天数，也不使用年份做全局硬过滤。
- `era` 表示知识适用的历史范围，不是游戏事件触发器。
- 默认卡拉迪亚世界观可以作为开放沙盒基线，但不是其他世界观的强制选项。
- 未来固定剧情模组可以另行增加事件门控和明确时间线，不影响默认开放沙盒。

## 后续实现前置条件

1. 单独建立编译端计划和只读对抗审查记录。
2. 明确 `time_scope` 的编译契约及静态知识、动态事件的权威边界。
3. 准备开局基线、事件更新、周报更新和读档重建的 fixture。
4. 以新 BuildId 实现和验证，不修改冻结 AWAKE 候选。

## 当前明确不做

- 不在 Worldbook Studio 首版 AI 草稿流程中新增复杂时间字段。
- 不把 1086 年或 1090 年的未来知识自动视为 1084 年开局 NPC 已知。
- 不通过“作者写了年份”推断事件已经发生。
- 不同步游戏目录，不启动 Bannerlord。
