## 一、一句话定义

> **世界书不是小说正文。它记录的是：一个 NPC 能知道、能理解、会怎么说的世界知识。**
> 不是让所有 NPC 都知道全部历史，也不是把一整段百科塞给 AI。
> —— 手册 v3 · A1.1

一句话里三个约束，缺一不可：
- **能知道**（权限，不是全知）
- **能理解**（认知水平，不是照本宣科）
- **会怎么说**（口吻，不是百科腔）

## 三、判定标准：一句话该归哪一类

**Assertion 的五种 `kind`**（手册 B5）：

| kind | 是什么 | 例 |
|---|---|---|
| `fact` | 客观发生/存在的事实 | 巴拉维诺斯由卡拉狄乌斯大帝建立 |
| `state` | 状态 | 帝国重心东移后仍是西部经济重镇 |
| `relation` | 关系 | 传承到戴·提尔家族旁支 |
| `interpretation` | 解释/价值判断 | （"正义的入侵"这类只能归这里，不能写成 fact） |
| `rumor` | 传闻 | — |

**工作顺序**（手册 B10）：
```
先按五领域归类 → 再拆条目边界 → 先登记官方来源 → 再生成档案
先写 fact / state / relation → 后写 interpretation / rumor
先做地理聚落简介 → 再做政治沿革和家族关系
先完成 P0 骨架 → 再补 NPC 本地生活表达
```

**时间维度**（手册 B2）：必须落 `era`，**历史事实不得写成 current**。`current_and_historical` 只能作过渡，不能作存档值。

## 四、视角与认知边界

- 每条表达**必须**写 `layer`（rumor / summary / detail / secret）+ `grants`（profile_id / scope / min_detail）；**不允许**只写"三种身份的说法"而不指定 profile 和 layer。（手册 B7）
- **低了解度身份不知道的就空着，不代为补全**——"知道"和"能完整说出来"不是一回事。（WRITING-RULES 1）
- **请求外的身份视角不产出表达**；表达里的身份必须是实体登记表中真实存在的 profile。（WRITING-RULES 14）
- 表达层是"该身份能转述的知识"，**不是散文创作**。（WRITING-RULES 8）

## 六、边界：什么不许写（手册 B9 + F 部分）

- 动态游戏所有权与当前战争结局
- 未经游戏数据支持的正式实体 ID
- 官方没给的精确年份
- 官方文本外的人物关系、额外人物
- 任何未登记的 AI 生成事实
- 旧四版成人化内容、战团未来 / CK3 扩展、未核实素材
- 现代心理学术语、21 世纪网络词、现实式安全词与价值观尾巴
- 未成年角色的性内容（**18+ 硬校验先于一切**）

**流程红线**：候选**不得**自动变成 approved / canon / compiled / published / runtime-ready；没有人工采纳的内容不得进入 `create-document`。

### 第 1 条为什么改（本机实测推翻）

我原先以为 `scope`（local/regional/national…）是"这条知识流传多远"，打算用它做"近处知道得细、远处只剩传闻"的梯度。

**实测证明我错了。** `WorldbookIdentityEvaluator.cs:104`：

```csharp
ScopeRank(evaluation.EffectiveScope) >= ScopeRank(rule.Scope)
```

`local=1 < regional=2 < national=3 < faction=4 < elite=5 < private=6`。
**scope 是"接触门槛"（保密层级），不是地理距离。`local` 是最低门槛，谁都够得着。**

实测：同一身份问同一句，scope 从 local 改到 private，六种**全部 known，毫无差别**。
→ 要做地理梯度，得用 `conditions.settlement_ids`，或用详细度维度。**不能用 scope。**

（另外实测：`requestedDetail` 是**上限**不是"想要多细"，请求 `rumor` 反而会被 blocked。容易踩反。）

### 第 5 条为什么加（本机实测发现）

门控 `not_found`——一条知识都没给——模型照样编：

> 士兵（门控没给）："今年雨水足，收成还好。不过税官总是狮子大开口。"

原因：真实提示词模板只对"跨会话记忆为空"写了"不要编造共同经历"，**对 `retrieved_knowledge` 为空没有任何约束**。

→ **只做内容分层不够，提示词层必须配合**，否则我们搭的知识壁垒在输出端直接失效。
→ 这条建议写进 `src/Prompts/NpcPromptTemplate.cs`（属主干侧，跨线）。
