## 一、这 20 条到底长什么样（先看结构）

**每条的骨架完全一样**，都是 `rumor` 档 + `detail` 档各一条，且 `detail` ＝
**「主题句」+ 一整段官方长文**（把 `rumor` 那句接在主题句后面）。

以「衣着与装饰」（`culture/clothing`）为例，正文实际是：

```
[rumor]  听人说，阿塞莱人是卡拉迪亚以南的纳哈撒沙漠——即青铜沙漠的主要居民。 ← 引错了
         （后面跟着整段阿塞莱文化的官方介绍：家族/族谱/巴努·阿塞拉/绿洲水源/商队）

[detail] 从沙漠的遮罩到森林的皮毛，穿什么由脚下的地决定。          ← 这句很好，贴题
         阿塞莱人是卡拉迪亚以南的纳哈撒沙漠——即青铜沙漠的主要居民。 ← 后面又是那段阿塞莱介绍
```

⇒ **看点**：**主题句是好的**（「穿什么由脚下的地决定」既贴题又有味道），
**坏的是拼在它后面的那坨官方文**——那段文讲的是阿塞莱的**民族起源与贸易**，**跟"穿什么"没关系**。

**⇒ 不是"没写"，也不是"引文乱"；是"好标题配错了料"。**

## 二、根因：一个「主题句 × 官方长文」的机械拼接

**20 条全部呈现同一个模式**：

| 位置 | 内容 | 质量 |
|---|---|---|
| `title` | 「衣着与装饰」「税赋」「商路与商队」 | ✅ **贴题、用词好** |
| `summary` | 「从沙漠的遮罩到森林的皮毛，穿什么由脚下的地决定。」 | ✅ **贴题、有味道** |
| `rumor` 档 | **官方长文的第一句**（阿塞莱起源／声望定义／军团凝聚力…） | ❌ **跑偏** |
| `detail` 档 | **= summary + 同一段官方长文全文** | ❌ **跑偏 + 冗长** |

⇒ **推断**：这批条目是**用"标题+主题句"当壳，去库里找一段现成长文塞进去**生成的，
**但"找"这一步没有按主题匹配**，而是**按"这个子域大概是哪个文化/系统"粗配**（如 `clothing` → 抓了阿塞莱文化总述）。

**证据（三条最典型）**：

| 条目 | 标题（好） | 引文实际讲什么（跑偏） | 差多远 |
|---|---|---|---|
| `culture/clothing` 衣着与装饰 | 穿衣由地决定 | **阿塞莱民族起源**（谁的后裔、绿洲水源） | 完全不搭 |
| `war/prisoners` 俘虏与赎金 | 活着的敌人比死了的值钱 | **小阵营是什么**（兄弟会/雇佣兵/收保护费） | 完全不搭 |
| `war/fortifications` 筑城与攻城 | 靠人守、靠人饿 | **军团凝聚力数值**（低于阈值会解散） | 完全不搭 |
| `geography/climate` 气候与季节 | 北寒冬南砾石 | **斯特吉亚人来自森林**（来源+毛皮贸易） | 只沾一个"北"字 |
| `economy/debt` 债务与赎金 | 迟早要还 | **声望是什么**（地位看法／通用性） | 完全不搭 |
| `economy/food` 食物与给养 | 锅灶先垮 | **部队每天消耗食物的机制说明** | **这条其实半对**（见下） |

⚠️ **注意 `food` 这条**：它引的确实是"食物"机制，**但那是游戏 UI 的说明文**（「你的部队（包括由电脑领导的部队）每天都要消耗食物」），
**读者是玩家，不是角色** —— 属于**另一种病**：**元游戏腔**（把系统说明当世界内知识）。

## 四、这 20 条的**共同点**（一句话）

> **标题和主题句都写对了，坏的是"底下垫的那段料"：
> 20 条里真正"完全不搭"的只有 9 条，5 条是"半对"，1 条根本不用改，
> 另有 2 条缺料、3 条放错抽屉。**

**⇒ 这是一个"配错料"的问题，不是"写作能力"的问题。**
**修法上，最省力的顺序是：先挪 C 堆 3 条（纯移动）→ 再补 B 堆 2 条（补 2 段料）→ 最后 A 堆逐条换料（真正要动的只有 9 条）。**

**⚠️ 但真正要紧的**：那 9 条"完全不搭"的里，有 **2 条（`food` / `tactics`）引的是游戏 UI 说明文**
（「你的部队每天都要消耗食物」「所有士兵都有默认的编队种类」）——
**这是"元游戏腔"，比引错料更严重**（读者是角色，不是玩家）。
**它证明生成流程里"找料"那一步会直接抓 `localization` 表里的 UI 文案**，v1 规范必须把这条堵死。

## 五、与既有规范的接口（为什么这件事必须现在修）

这 20 条**正好是"条目撰写规范 v1"最需要的**反面教材：

| 现象 | 该写进 v1 的条目 |
|---|---|
| 好标题 + 错料 | **「一料一用」原则**：一段官方原文**只用在一个主题上**，不得跨主题复用 |
| `detail = summary + 官方长文全文` | **禁止机械拼接**：正文须按主题**裁剪**官方文，不得整段倒进去 |
| 「你的部队每天要消耗食物」 | **去元游戏腔**：不得把 UI/机制说明当世界内知识（**禁"你/玩家/界面"**） |
| `roads`/`sea_routes` 零引文 | **禁占位句**：「这种事，问谁也说不周全」这类凑数句不得入库 |
| `resources/arts/war_history` 三条错格 | **命名空间口径**：一个 subdomain 只能装同类（矿归矿、人归人） |
