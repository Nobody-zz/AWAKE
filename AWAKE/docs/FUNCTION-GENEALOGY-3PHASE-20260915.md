# 我要提醒的三件事（不是功能，是判断）

1. **周报最划算的一招是"给它一个作者"。** 同一件事由自家书记官、宫廷史官、仇家分别写，立场不同——**能力成本几乎为零，但玩家会记很久**。这是"从数据变文学"的那一步。
2. **指令识别里最保命的不是"能听懂"，是"听不懂就说听不懂"。** 猜错的指令会改坏存档。
3. **第二阶段的性质是断崖，不是延续。** 第一阶段是文字往返，第二阶段要真改游戏状态。**先做一条最窄的**（例如"劝降一个守军"），把"意图→动作→结果"这条链证死，再铺开。
