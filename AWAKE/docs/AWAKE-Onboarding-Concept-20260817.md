# AWAKE 游戏引导增强方案（2026-08-17）

> 状态：概念方案，未进入实现；需 grill-me / PLAN 后再写代码。
> 原则：只借鉴 AF 的“自动提示 + 多步引导 + 状态持久化”设计，不复制 AF 代码、UI 或美术资产。

## AF 值得借鉴的做法

- 地图日更 tick 中自动显示系统提示：`按 X 键打开终端`，重复直到玩家熟悉入口。
- 独立 `ModOnboardingBehavior` 处理 API 首次配置、修复、重开引导等流程。
- 终端内保留“重新进行首次引导”入口，方便换 Provider 后重新配置。

## AWAKE 现状

- `AwakeOnboardingService` 只会在玩家主动按终端快捷键后弹出，且只弹一次。
- 没有自动触发，没有分步进度，没有存档持久化，也没有“下一步”闭环。
- 结果是玩家不知道 U 键，就永远看不到引导。

## 目标体验

新战役进入安全状态后自动弹出“醒世 · 引导”，按步骤完成：

1. 欢迎与隐私说明：说明本地/云端 Provider，云外发默认关闭。
2. AI 配置：检测 Provider/路由健康；未配置时提供“打开 AI 设置”，配置成功后自动进入下一步。
3. 打开命令台：引导玩家按当前配置键打开命令台，或直接提供“打开命令台”按钮。
4. 第一次 NPC 对话：在城镇/场景有候选 NPC 时，引导选择 NPC 并发送第一句话。
5. 查看通讯录历史：打开通讯录，查看历史并固定一条记录。
6. 完成：写入完成状态，不再自动打扰。

## 触发规则

- `CampaignSessionReady` 后，在安全地图/城镇菜单状态检测引导状态。
- 未完成且当前无对话、无覆盖层、无战斗时自动弹出；绝不打断战斗或原版对话。
- 未完成时每隔 `GuideRepeatIntervalDays`（默认 2 游戏日）自动提醒一次。
- 玩家选择“跳过本次”后，本次战役不再自动弹出，但仍可在命令台/MCM 手动重开。
- 玩家选择“永久跳过”后，写入 MCM/存档状态，不再自动弹出。

## 持久化

- 新增 `awake.onboarding.v1` 存储文档，记录完成步骤、跳过标记、最后提醒日。
- 跟随战役存档；新战役重新开始，但“永久跳过”可跨战役生效。

## MCM

- `EnableInGameGuide`：默认开启。
- `GuideRepeatIntervalDays`：默认 2。
- `OpenGuideAgain`：手动重新打开引导。
- `DisableGuideForever`：永久关闭自动引导。

## 风险与控制

- 防打扰：只在地图/菜单安全状态触发，有重复间隔，可跳过。
- 防误导：AI 未配置时不让玩家进入 NPC 对话步骤。
- 防旧档骚扰：已完成的存档不再触发；未完成的旧档仍可补引导。
- 可测试：SdkSmoke 覆盖步骤状态机、持久化、跳过与重开。
