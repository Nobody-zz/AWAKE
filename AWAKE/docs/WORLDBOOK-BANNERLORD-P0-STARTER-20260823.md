# AWAKE Bannerlord 世界知识第一批制作清单

用途：这是面向 AWAKE 世界书作者的**第一批可直接开工目录**。它按《骑马与砍杀 II：霸主》的实际游戏对象组织，而不是按泛中世纪百科组织。

本清单暂时不裁定具体时间线、史实版本和参考资料冲突，只规定：**先把哪些游戏对象和知识类型做出来。**

---

## 一、Bannerlord 对应的基础对象

第一批内容围绕这些游戏对象展开：

- 六种主要文化：帝国、瓦兰迪亚、巴旦尼亚、斯特吉亚、库赛特、阿塞莱；
- 八个主要王国实体：北部帝国、南部帝国、西部帝国、瓦兰迪亚、巴旦尼亚、斯特吉亚、库赛特、阿塞莱；
- 三类聚落：城镇、城堡、村庄；
- 主要人物类型：领主、家族成员、同伴、村庄头人、乡村显贵、工匠、商人、帮派头目、酒馆人物、赎金经纪人；
- 主要移动实体：玩家队伍、领主队伍、商队、村民队伍、军队、巡逻队、匪徒队伍；
- 主要军事对象：征召兵、文化兵种树、贵族兵种、佣兵、民兵、驻军、攻城军和守军；
- 主要经济对象：村庄产出、城镇市场、工坊、商队、税收、繁荣、粮食、军粮和贸易路线；
- 主要战役对象：战争、和平、停战、围城、劫掠、俘虏、赎金、领地变化和家族关系变化。

### 重要建模原则

- 帝国是一个文化，但游戏中有北部、南部、西部三个帝国王国实体；
- 城镇、城堡和村庄不能混写成“聚落”；它们在治理、经济、驻军和 NPC 身份上不同；
- “贵族”“平民”“士兵”不是 Bannerlord 原生的完整知识等级，需要由 AWAKE 根据 `Occupation`、家族、聚落、文化、年龄和技能派生；
- 村庄显贵、头人、工匠、商人和帮派头目是不同的知识来源，不能全部合并为“普通 NPC”；
- 兵种名称是游戏数据，兵种传统、社会评价和军人说法需要世界书另行解释。

# 二、第一批 P0：世界骨架

这一批完成后，NPC 才能回答“我在哪里、这里属于谁、附近有什么人和势力”。

## P0-A：卡拉迪亚总览（10 条）

- [ ] `world.calradia.overview`：卡拉迪亚整体概览
- [ ] `world.calradia.regions`：主要区域与方向
- [ ] `world.calradia.cultures`：六种主要文化总览
- [ ] `world.calradia.kingdoms`：八个主要王国实体总览
- [ ] `world.calradia.settlement_types`：城镇、城堡、村庄的区别
- [ ] `world.calradia.travel`：旅行、道路、队伍和消息传播
- [ ] `world.calradia.factions`：王国、家族、商队、匪徒和军队的关系
- [ ] `world.calradia.common_terms`：国家、领主、家族、军队、村庄等基本称呼
- [ ] `world.calradia.public_threats`：盗匪、战争、饥荒和道路危险
- [ ] `world.calradia.known_places`：NPC 应该知道的主要地点类别

## P0-B：文化总览（每种文化 6 条，共 36 条）

对六种文化分别制作以下六条，不要只写一篇总文化百科：

- [ ] `culture.*.overview`：文化总体印象
- [ ] `culture.*.social_order`：社会等级与身份关系
- [ ] `culture.*.livelihood`：主要生计和经济方式
- [ ] `culture.*.military_tradition`：军事传统和主要兵种印象
- [ ] `culture.*.customs`：婚姻、家庭、待客、葬礼和节庆
- [ ] `culture.*.outsider_view`：对邻近文化和外来者的看法

六种文化分别为：

- [ ] 帝国文化
- [ ] 瓦兰迪亚文化
- [ ] 巴旦尼亚文化
- [ ] 斯特吉亚文化
- [ ] 库赛特文化
- [ ] 阿塞莱文化

## P0-C：王国总览（每个王国 5 条，共 40 条）

对八个王国实体分别制作：

- [ ] `kingdom.*.overview`：国家概览
- [ ] `kingdom.*.ruler_and_clans`：统治者与主要家族
- [ ] `kingdom.*.territory`：领地、核心聚落与边界
- [ ] `kingdom.*.enemies_and_allies`：主要敌对和外交关系
- [ ] `kingdom.*.public_reputation`：普通人、商人和士兵对该国的印象

八个王国实体：

- [ ] 北部帝国
- [ ] 南部帝国
- [ ] 西部帝国
- [ ] 瓦兰迪亚王国
- [ ] 巴旦尼亚王国
- [ ] 斯特吉亚王国
- [ ] 库赛特汗国
- [ ] 阿塞莱苏丹国

帝国三国不能只复制同一份“帝国文化”档案。应分别写它们的政治目标、统治者、家族关系、军队处境和普通人称呼。

# 三、第一批 P0：聚落与地方知识

Bannerlord 的 NPC 大量围绕聚落活动，所以地方知识应早于冷门历史。

## P0-D：每个主要城镇 8 条

对每个主要城镇建立一组档案：

- [ ] `settlement.town.*.overview`：城镇概览
- [ ] `settlement.town.*.owner`：所属王国、领主和家族
- [ ] `settlement.town.*.culture`：城镇文化与人口印象
- [ ] `settlement.town.*.economy`：主要产业、市场和物资
- [ ] `settlement.town.*.bound_villages`：关联村庄和供应关系
- [ ] `settlement.town.*.garrison`：驻军、守卫和防御
- [ ] `settlement.town.*.notables`：商人、工匠、帮派头目等重要人物类型
- [ ] `settlement.town.*.local_rumors`：本地公开传闻和常见问题

第一阶段不要求立刻把每个城镇写成完整百科，建议先覆盖每个文化最重要的城镇，再扩展到全部城镇。

## P0-E：每个主要城堡 6 条

- [ ] `settlement.castle.*.overview`：城堡概览
- [ ] `settlement.castle.*.owner`：所属领主和家族
- [ ] `settlement.castle.*.strategic_role`：战略位置和控制价值
- [ ] `settlement.castle.*.garrison`：守军和防御
- [ ] `settlement.castle.*.bound_villages`：物资来源和关联村庄
- [ ] `settlement.castle.*.siege_memory`：围城、易主和战争传闻

## P0-F：每个主要村庄 7 条

- [ ] `settlement.village.*.overview`：村庄概览
- [ ] `settlement.village.*.bound_town`：隶属城镇
- [ ] `settlement.village.*.production`：主要生产和物产
- [ ] `settlement.village.*.headman`：头人和村庄显贵
- [ ] `settlement.village.*.tax_and_duty`：税收、征粮和劳役
- [ ] `settlement.village.*.local_dangers`：盗匪、战争和自然风险
- [ ] `settlement.village.*.village_rumors`：村民传闻、禁忌和地方记忆

# 九、初步实际工作量建议

不要一开始制作所有人物和所有地点的完整文本。建议分三轮。

## 第一轮：可用骨架

目标：约 80–120 份档案。

- 10 条世界总览；
- 36 条文化基础；
- 40 条王国基础；
- 每种文化 1 条兵种体系，共 6 条；
- 10–20 条聚落类型和地方知识；
- 10 条人物身份知识画像；
- 10 条战争与经济基础规则。

## 第二轮：玩家高频对象

目标：约 150–250 份档案。

- 主要城镇；
- 主要城堡；
- 主要村庄；
- 主要领主；
- 主要家族；
- 主要兵种和军队；
- 商队、工坊、市场和赎金系统；
- 当前高频战争与周报事件。

## 第三轮：丰富与差异

目标：持续扩展。

- 地方传说；
- 冷门人物；
- 家族秘密；
- 文化内部地区差异；
- 战争不同阵营的记忆；
- 贵族圈知识；
- 成人扩展、未来层和其他世界观内容。

# 十、第一批不建议制作的内容

以下内容不是不能做，而是不应阻塞第一版：

- 每个普通 NPC 的个人百科；
- 每件装备的长篇历史；
- 每个村庄的独立传说；
- 复杂的古代神话体系；
- 尚未决定的幕后真相；
- 与当前玩家游戏行为无关的冷门历史；
- 需要未来时间线才能成立的国家和人物；
- 成人拓展包的详细内容；
- 把游戏机制数值直接写成 NPC 会说的世界知识。

---

# 十一、第一批完成标准

第一批不是“所有条目都写完”，而是满足以下条件：

- [ ] NPC 能识别自己所在的文化、国家和聚落类型；
- [ ] NPC 能解释自己所在地区靠什么生活；
- [ ] NPC 能区分城镇、城堡、村庄和军队；
- [ ] NPC 能识别主要王国和文化；
- [ ] 士兵能谈论战争常识和兵种；
- [ ] 商人能谈论市场、物资、商路和风险；
- [ ] 头人能谈论村庄、税收和领主要求；
- [ ] 贵族能谈论家族、领地和王国政治；
- [ ] 普通平民不会自动说出贵族机密；
- [ ] 不知道时可以转介给合理的中介 NPC；
- [ ] 周报事件有可供不同身份读取的摘要模板；
- [ ] 重要条目可以在 Studio 中按身份预览。

---

## 最终建议

第一批世界书不要从“卡拉迪亚完整历史”开始，而要从玩家实际会遇到的游戏对象开始：

```text
文化
→ 王国
→ 聚落
→ 家族与领主
→ 职业与身份
→ 经济和军队
→ 战争与周报事件
→ 传闻、秘密和扩展内容
```

这条顺序最贴合 Bannerlord 的实际游戏结构，也最容易让世界书读取和 NPC 身份差异先产生可观察效果。
