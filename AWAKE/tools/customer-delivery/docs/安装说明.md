# 安装说明

将整个 `awake-customer-<build_id>` 目录解压到新的本地目录，不要覆盖旧包或把文件混入旧目录。

在 Windows PowerShell 中分别运行三项入口。Worldbook Studio 与 Persona Workbench 使用自己的本地端口；UI Workstation 使用 loopback 地址，并通过 WBS readback 校验文档版本后导航。

停止时先使用 `ui-workstation/stop-ui-workstation.ps1`，再关闭两个领域工作站。若进程异常退出，检查对应工作站的运行时目录并重新启动，不要删除仍被活动实例持有的锁。

本地 AI（可选）：

1. 在本机启动 Ollama，并确认目标模型已存在。
2. 将 Worker 地址限制为 `http://127.0.0.1:11434`，不要填写公网地址。
3. 先运行 Worldbook Studio 的健康检查，再执行“参考资料 → 事实 → 身份表达 → 建档”流程。
4. AI 生成结果必须由作者逐条采纳；`needs_review` 档案需继续人工检查后才能进入后续 authority 流程。

不要直接把 `export/WorldbookV2` 下的 staging 结果当作当前正典；发布前必须完成批准、CompileProof、manifest 校验和明确的发布操作。
