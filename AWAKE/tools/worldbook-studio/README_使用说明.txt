AWAKE Worldbook Studio

这是给世界书内容编辑者使用的本机编辑器，不需要预先安装 .NET，也不需要使用 PowerShell 或命令行。

如果你是第一次编辑世界书，请先阅读同目录下的：
“新手指引_世界书内容编辑者.md”

它会用中文一步步说明如何新建档案、填写客观事实、设置 NPC 知识权限、编写不同身份的表达，以及如何使用 AI 建议。

使用方法
1. 将整个压缩包解压到任意普通文件夹。
2. 双击 Awake.WorldbookStudio.Launcher.exe。
3. 第一次启动时选择默认工作区或其他文件夹。
4. 浏览器会自动打开本机编辑器；如果没有打开，请点击“复制地址”，再手动粘贴到浏览器。

开发者本机测试入口
- 当前唯一测试包：tools\worldbook-studio\artifacts\current-test\WorldbookStudio\Awake.WorldbookStudio.Launcher.exe
- 当前包身份记录：tools\worldbook-studio\artifacts\current-test\CURRENT-TEST-PACKAGE.json
- 历史候选包都在 artifacts\archive\ 下，不要从历史目录启动。
- 不要根据文件修改日期判断版本；以 CURRENT-TEST-PACKAGE.json 和包内 manifest.json 的哈希为准。

工作区
- 默认位置：Windows 文档\AWAKE\WorldbookStudio
- 编辑内容、审核记录和导出文件都保存在工作区。
- 程序包目录和 Bannerlord 游戏目录不会作为工作区使用。
- 如需换电脑或换存档，可复制整个工作区；不要只复制程序目录。

退出
- 关闭启动器窗口会先安全关闭本机 Web 编辑器。
- 不要在任务管理器中结束 Web 进程；如果浏览器页面关闭，启动器仍负责管理它。

故障排查
- 5077 端口被占用：关闭占用该端口的其他本机程序后重试。
- 工作区不可写：选择一个有写入权限的普通文件夹，不要选择游戏 Modules、PlayerExports 或程序包目录。
- 日志位置：%LOCALAPPDATA%\AWAKE\WorldbookStudio\logs

AI 辅助
- AI 未配置时，编辑、校验、预览和导出仍可使用。
- “从资料生成待审核档案”适合单份资料；“批量生成多个待审核档案”适合一次导入多份资料。Quick Authoring 的顺序是：导入资料 → 填写整理目标 → 选择内容范围 → 生成待审核草稿 → 查看来源和警告 → 人工采纳 → 创建待审核档案。
- 点击“建立批量任务”后请等待项目状态读取完成；按钮变成“确认并开始提取事实”才进入下一步。成功后程序会自动打开“审核 AI 提取的事实”，不会再出现一个隐藏的“下一步”按钮。
- 如果显示“正在读取项目状态”，不要连续点击；等待完成或点击“刷新批次状态”。如果显示“没有等待提取事实的项目”，先刷新批次状态，确认左侧项目不是“已提取、待审核”或“已完成”。
- “从资料生成待审核档案”可以把本地 TXT、Markdown、YAML、JSON 或直接粘贴的资料交给 AI，一次生成完整待审核候选；不填写身份视角时不会默认生成 NPC 身份表达。兼容分阶段流程仍可在高级入口中使用。
- AI 草稿必须逐条人工采纳；修改卡片文字后需要重新点击“采纳”，不会自动写入正典。
- 参考资料只在本次 Studio 会话中使用，不会自动登记为来源，也不会自动联网抓取网页。
- AI 面板支持“先做本地检查”，无需 API Key 也能检查占位内容、空字段和明显权限问题。
- 云端 Provider 在 AI 面板的“云端设置”中填写；配置只保存在本机用户目录并使用 Windows 本机加密保护。
- API Key 不会写入世界书、Studio 工作区、普通日志或导出包；输入框留空表示保持已保存的 Key。
- AI 检查重点包括内容补全、事实纠偏、知识权限、阶层身份、表达层级、世界观文风、NPC 语气和领域表达。
- 如果提示本机安全会话失效，工作室会先自动刷新并重试一次；只有自动刷新失败时，才需要关闭旧窗口、只保留一个新版工作室窗口，再点击“刷新”。

本机 AI Worker（外部前置，可选）
- 本机 AI 不是内置模型：它需要一个已经在本机运行、并已完成配置的外部 Worker 服务。
- 程序包内不包含 Worker，也不包含任何模型文件；它不会自动下载或自动安装。
- 使用前必须由提供 Worker 的一方在本机配置好地址与密钥（环境变量 WORLD_BOOK_LOCAL_WORKER_URL，以及 WORLD_BOOK_LOCAL_WORKER_SECRET_ENV 指向的密钥变量），再从启动器打开工作室。
- 当前版本的界面不提供填写本机 Worker 地址的入口；面板中只能选择“本机 AI Worker / 云端 AI Provider”，不能在此处录入本机地址。
- 没有 Worker 时，编辑、检查并保存、预览、导出和“先做本地检查”都仍然可用；只有“生成待审核草稿”“批量生成”这类需要模型的功能不可用。
- 第一次点击“生成待审核草稿”就失败时，按顺序检查：① Worker 服务是否已启动；② 地址与密钥环境变量是否已在启动前设置；③ 是否改用云端 Provider；④ 是否先不使用 AI。
- 完整说明见包根目录 docs\本地Worker配置.md。
- 不要连接来历不明的本机服务或云端地址；离线资料只发给 loopback（127.0.0.1 / localhost / ::1）地址。
