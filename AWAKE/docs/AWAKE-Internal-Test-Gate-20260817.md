# AWAKE 内测门槛（2026-08-17）

> 用途：判断“能不能初步给玩家内测”，以及各阶段要补齐什么。

## 内测分级

### Level 0：技术内测（好友 / 开发群，10-20 人）

目标不是“好玩”，是验证“能装、能跑、能聊、不炸档”。

- [ ] 安装包完整：AWAKE + Marcus AI Framework + 前置依赖，按游戏版本 `v1.3.15` 匹配，无缺失文件。
- [ ] 新档能加载，旧档能读，存档后重开不崩溃。
- [ ] Companion 自动启动，AI Provider 可连通；云端路线需允许 route 云外发。
- [ ] 核心闭环可走通：命令台 -> 选 NPC -> 对话 -> 流式回复 -> 关闭；遭遇“面谈（醒世）”也能进入。
- [ ] 通讯录历史、历史 Tab、固定/取消固定可用，关游戏重开后仍在。
- [ ] 日志无 P0 崩溃，`world_state_final_drain_complete`，无 dropped 写。
- [ ] MCM 默认值 fail-safe：云外发默认关，主动对话默认关或低频。
- [ ] 提供“已知问题 + 日志收集 + 存档备份”说明。

### Level 1：玩法内测（封闭邀请，30-50 人）

目标是可以当成“一个 AI 模组”连续玩。

- [ ] Batch 2 落地：主动对话有确定性触发与可解释理由，不再纯概率高频刷。
- [ ] 大地图 NPC 对话入口统一：定范围 -> 定格 -> 选择人物 / 公开喊话。
- [ ] 记忆与关系跨存档会话可靠：读档后 NPC 还记得对话与关系变化。
- [ ] 2 小时以上连续游玩无崩溃、无 UI 失焦卡死、无长等待锁死。
- [ ] 世界书加载正常，NPC 对话能引用基础世界观内容。
- [ ] 中英文文本不缺失，MCM 分组清晰。
- [ ] 测试反馈表：崩溃日志、复现步骤、对话内容、期望行为。

### Level 2：公开 Beta

- [ ] 内容包或默认内容达到可宣传的完整度。
- [ ] 世界书管理、开发者诊断等工具达到可维护程度。
- [ ] 性能与 token 预算有明确上限，普通玩家不需要懂配置也能玩。
- [ ] 安装包、FAQ、已知问题、反馈渠道齐全。

## 当前状态判定

- 现在可以做 Level 0 的前置准备，但还不能正式发内测包。
- 阻塞项：Batch 1 尚未进游戏验收；ContactHubHistory 仍是 `pending_game`；主动对话与地图入口仍是 P1 队列。
- 先完成一次你自己的完整游戏验收：云外发通、对话通、存档通、日志无 dropped。

## 建议的第一步

1. 你进游戏验收 Batch 1 与 ContactHubHistory。
2. 通过后把主动对话默认改为关闭或低频，生成 Level 0 测试包。
3. Level 0 测试包只包含：AWAKE 运行时 + Marcus 框架 + 安装说明 + 已知问题 + 日志收集说明。
4. Level 0 稳定后，再走 Batch 2 grill-me / PLAN，进入 Level 1。
