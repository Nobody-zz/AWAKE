# AUDIT-20260917 · 判断层「初步枚举」的红队复检

**被测对象**：`docs/DESIGN-20260917-检索之前的判断层.md` **附录 A**（八段 39 点枚举，本轮新建）。

**做法同上一份**：抽可核验断言 → 逐条证伪。附录 A 里绝大多数是 `[材: …]` 标注，
所以这次红测**专打那些"没有"**。

## 〇 结论

**5 处 P0，全部是同一类错：把「有」写成了「没有」。** 加上 3 处 P1、1 处 P2。

| 级别 | 数 | 共同点 |
|---|---|---|
| P0 | 5 | 全是否定式断言写错（"没有／整段缺席"） |
| P1 | 3 | 举例松、把推断写成事实、说法不够实 |
| P2 | 1 | 引用细化不到位 |

⇒ **写「没有」比写「有」危险得多**：写"有"只要举一个例；写"没有"漏查一处就假。
本节 5 处错**全是"没有"**，这就是证据。

## 一、P0-①：入口清洗**早就有了**（而且今天刚加的）

**原稿（第〇段 #4）**：「形态脏了：错别字／同音／简写／繁简／全半角／词中空格 ——
检索侧散着一些零碎处理（如 `NameLikeMinSharedTerms`），**没有统一的入口清洗**」

**反证**：`WorldKnowledgeQueryService.cs:62` 就是入口清洗，且注释就写在那一行上方：
```csharp
query.PlayerText = NormalizeQueryText(query.PlayerText);   // :62
```
`NormalizeQueryText`（`:252`）做了**四件**事：
1. `FormKC` —— 全角字母/数字/空格→半角、连字与罗马数字归一；
2. 去零宽与不可见字符（`U+200B~200D`／`U+FEFF`）；
3. 两端去空白（**词中空白与标点不动**——注释明写 09-16 量过动它会再造空串）；
4. **繁→简**，走系统 `LCMapStringEx`，**不造表**（理由写在注释里：手工造表＝对样本过拟合）。

还带一条**"归一化之后必须再判一次空"**（因 `？？？` 归一化后为空）。

⇒ 我写"没有统一的入口清洗"，而它**在文件里、在注释里、还是当天加的**。**没查就写。**
**已改**：拆成 #4（已有，列出四件事与两条"明确不碰"）＋ #4b（错别字/同音确实是另一条线）。

## 二、P0-②：「说多少」**有雏形**，我写成了"没有"

**原稿（第一段 #25）**：「说多少（说满还是留一半、藏拙还是卖弄）｜没有」

**反证**：详细度档位已经在做这件事 ——
`Detail`／`MinDetail`（`WorldKnowledgeModels.cs:51/62`，取值 `rumor`/`summary`/`detail`/`secret`）、
`DetailRank`（`WorldbookIdentityEvaluator.cs:202`）、`EffectiveDetail`，
检索层按 `DetailRank` **降档**并标 `partial`（`WorldKnowledgeQueryService.cs:96`）。
⇒ 缺的是"同一身份这次**主动**想留一半"，**不是没有机制**。
**已改**为「有雏形（按身份定量）＋ 缺"主动选择说多少"」。

## 三、P0-③：「立场」有**阵营归属**，我写成了"没有"

**原稿（第四段 #29）**：「立场（他偏向谁、忠于谁）｜没有」

**反证**：`_clanName`／`_kingdomName`／`_heroKingdomId`（`NpcDialogueService.cs:47/48/53`）
都填进了 `ContextSnapshot`，`WorldbookQuery` 里也有 `KingdomId` 并参与身份闸。
（`Allegiance`／`Loyalty` 全仓零命中 ⇒ "态度性立场"确实没有，但**不能写成"立场没有"**。）
**已改**为「**态度性**立场：没有；阵营归属**有**」。

## 四、P0-④：用「传闻」当缺失项，撞了本仓的同名词

**原稿（第二段 #19）**：「要不要连"别人对他的评价／传闻"一起查｜没有」

**反证**：`rumor` 在本仓**不是"传闻"**，是**详细度档位**（`WorldEventContracts.cs:774`
把四个档位列成 `{ "rumor", "summary", "detail", "secret" }`）。
把它写成"缺失的一项"，会让后续读的人以为"库里没有传闻类内容"，**方向完全错**。
**已改**：该项正名为「**别人的评价**（声誉）｜没有」＋ 一句"`rumor` 是档位、不是这个"。

## 五、P0-⑤：「整段缺席」与表里的「已有」自相矛盾

**原稿（A.1 第 1 条）**：「入口那一段（第〇段）和回写那一段（第五段）**整段缺席**」
