# 故障排查

- `not_configured`：尚未配置本地 Worker；仍可进行无 Worker 的草稿编辑。
- `ready`：Worker 可通过 loopback 健康检查。
- `timeout`：Worker 未在规定时间内返回；保留草稿并重试，不自动重复不确定请求。
- `transport_error`：连接失败或协议不匹配；检查本地 Worker 地址、协议版本和模型配置。
- `unknown`：结果无法确定；先查看 receipt/readback，再执行恢复操作。
- `needs_review`：内容已进入 Worldbook Studio 草稿，但尚未写入正典。

`409` 表示版本、实例或指纹冲突；先刷新并核对 workspace、document、revision 和 content hash。
