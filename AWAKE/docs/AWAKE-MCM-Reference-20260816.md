# AWAKE MCM 菜单参考

> 首版 2026-08-16 ｜ 分组与条目重写于 2026-09-14（MCM 分组重排）。
> 本文描述**游戏内 MCM → AWAKE 页实际渲染出来的样子**，以 `src/AwakeConfig.cs` 为准。

## 一个前提：序号是本地化文本的一部分

组名里的 `0. / 1. / 2.` **不是代码排的，是写死在字符串里的**，见 `awake.mcm.group.*`。
排序由 `SettingPropertyGroup(..., GroupOrder = n)` 决定（越小越前），序号只是给玩家看的第二重线索。

因此**任何"插入 / 合并 / 重排分组"都必须同时改三处**：

1. `src/AwakeConfig.cs` 里 36 处 `SettingPropertyGroup` 的 fallback 字面量；
2. 两个语言文件的组名键（`ModuleData/Languages/awake_strings.xml` 与 `CNs/awake_strings-zh-HANS.xml`）；
3. 指向组名的玩家可见文案——例如 `awake.dialogue.cloud_export_disabled` 里写着"请到 MCM ◯◯ 中打开云外发"。

组内顺序由 `Order` 决定，**只在组内生效**。

## 分组总览（6 组 / 36 项）

| # | 组名 | 项数 | 管什么 |
|---|---|---|---|
| 0 | AI 链路 | 10 | 对话用的 AI 服务：地址、模型、Key、连通性验证 |
| 1 | 图片生成 | 9 | 立绘出图：**独立的地址与独立的 Key** |
| 2 | 授权与外发 | 3 | 三个许可开关 |
| 3 | 对话与场景 | 6 | 人物选取、场景按键、命令台快捷键 |
| 4 | 主动行为 | 5 | NPC 主动、事件引擎、游戏内引导 |
| 5 | 开发者与诊断 | 3 | 开发者菜单、诊断报告、整体自检 |

与 2026-08-16 版的差别：

- 「3. 命令台」（原单项组）并入「对话与场景」；
- 「4. 数据与调试」拆成「授权与外发」与「开发者与诊断」——原先它把隐私授权和调试工具塞在同一组；
- `允许 AI 对话与结算` 从「AI 链路」移到「授权与外发」（它管的是许可，不是配置）；
- `AI 自检` 从「AI 链路」移到「开发者与诊断」（它刷新的是整栈状态，不只是链路）；
- 图片生成组前移到 AI 链路正下方，两块 AI 相关设置相邻。

## 0. AI 链路（`awake.mcm.group.ai_link`）

只装「填配置 + 验证连通」。

| Order | 控件 | 默认 |
|---|---|---|
| 0 | AI 链路状态（只读） | — |
| 1 | AI 服务类型（下拉） | — |
| 2 | 服务地址 | `https://api.openai.com/v1` |
| 3 | 模型名称 | `gpt-4o-mini` |
| 4 | 这是云端服务 | 开 |
| 5 | 模型读取状态（只读） | — |
| 6 | 〔输入或替换 API Key〕按钮 | — |
| 7 | 〔保存配置并应用〕按钮 | — |
| 8 | 〔拉取可用模型〕按钮 | — |
| 9 | 〔测试连接〕按钮 | — |

密钥只写入本机保护存储，不进入 MCM、存档或日志。

## 1. 图片生成（`awake.mcm.group.image`）

与「0. AI 链路」相邻，但**两者不共享地址、也不共享 Key**。
原因见 `docs/PLAN-AI-PORTRAIT-IMAGE-20260913.md`：AI 链路的 Key 存在 Runtime 进程（net8）的保护存储里，模组进程（net472）读不到、也没有回读接口；生图要在模组侧自己出网，就必须有自己的地址和自己的钥匙。

| Order | 控件 | 默认 |
|---|---|---|
| 0 | 本组与 AI 链路分开（只读说明） | — |
| 1 | 出图接口形状（下拉：Player2 / OpenAI 兼容） | Player2 |
| 2 | 出图服务地址 | 空 |
| 3 | 出图走云端服务 | 关 |
| 4 | 〔输入或替换出图 API Key〕按钮 | — |
| 5 | 出图宽度（像素，128–2048） | 512 |
| 6 | 出图高度（像素，128–2048） | 512 |
| 7 | 〔测试出图〕按钮 | — |
| 8 | 出图状态（只读） | — |

尺寸是"请求值"，服务端有权不遵守；落盘与布局一律以实际像素为准。
〔测试出图〕会真实消耗服务端额度，路径会回显。

## 2. 授权与外发（`awake.mcm.group.auth`）

三个开关都是"许可"而不是"配置"，集中在一组，避免玩家漏掉那个默认关闭的总开关。

| Order | 控件 | 默认 |
|---|---|---|
| 0 | 允许 AI 对话与结算 | **关** |
| 1 | 启用云外发 | 开 |
| 2 | 允许外发玩家状态 | 开 |

注意 Order 0：**默认关闭**。不打开它，AWAKE 只走本地兜底文案，不提交对话、不外发数据、不结算 AI 产出的关系与世界状态。

## 3. 对话与场景（`awake.mcm.group.scene`）

| Order | 控件 | 默认 |
|---|---|---|
| 0 | 场景选人最大距离（8–150 米） | 60 |
| 1 | 启用场景可视化选人 | 开 |
| 2 | 近到远选人键 | `[` |
| 3 | 远到近选人键 | `]` |
| 4 | 场景喊话键 | `V` |
| 5 | 命令台快捷键 | `U` |

按键一律按 InputKey 名称解析，`[ ]` 这类字面键也接受。
