## 14. ⚠️ 仓库状态异常（09-15 发现，非本线造成）

本工作区的 `.git` **索引与对象库不同步**：索引引用 **2343** 个 blob，其中 **611 个本机不存在**（26%）。

- **分布**：`AWAKE/docs` 278／`AWAKE/tools` 190／`AWAKE/ModuleData` 79／`AWAKE/src` 50／`AWAKE/GUI` 7／根文件与 `AWAKE.Tests` 各 1
- **症状**：不带 pathspec 的 `git status` 与 `git diff --cached` 直接 `fatal: unable to read <sha>`
- ✅ **实测可用**：带 `-- <路径>` 的 `git status` / `git diff --cached --name-only -- <路径>` **都能跑**
- ⇒ **提交纪律里"提交前必查 `git diff --cached --name-only`"这条，现在必须带 pathspec 才执行得了**
- ⇒ `git commit -F <msg> -- <精确路径>` 仍可用（按 pathspec 建临时索引，不需要那 611 个 blob）
- ⚠️ **推断（未实测）**：无 pathspec 的 `git commit` 会失败（要写整份索引的树）。**没跑过，不当结论用**
- ⚠️ **不要无差别 `git add` 去"修"**：无法确认索引里那侧与工作区哪侧更新（该索引很可能是**从另一个工作副本带来的**）。要修，**先备份 `.git/index`** 再逐类判断

### 17.2 ⚠️ 踩到的坑：**CoverChildren 父级里不能放 StretchToParent 子级**

原来给「最新一条」画左侧 2px 金条，写法是 `Widget Fixed宽2 / HeightSizePolicy="StretchToParent"`，塞在 `HeightSizePolicy="CoverChildren"` 的行容器里。

**后果**：金条反向把行撑到「父级可用高度」（415），再被父级 CoverChildren 收上去 ⇒ 每行 415、对话列表 1265、整个面板被推成 **960×3115**。最高控件 `x=955, y=-2215`。

**取证（一手，非社区样本）**：扫官方五个模块 430 个 Prefab、4415 个 CoverChildren 父级——

- 「CoverChildren 父 × StretchToParent 子」只出现 **12 次**，且 **11 次父级是 GridWidget**（格子布局，机制不同，格子不继承父级尺寸）；
- 非格子的只有 `OrderOfBattle.Formation.xml` 2 处（高亮圈，另有 DimensionSyncWidget 供高）。
- 对照组：「Fixed 父 × StretchToParent 子」**1501 次**——这才是官方常规组合。

**正解（官方一手）**：给「装饰件匹配可变高内容块」用 `DimensionSyncWidget`。

- `Native/GUI/Prefabs/GameMenu/GameMenu.xml:73` —— 装饰条同步旁边那个 `CoverChildren` 列表的高度；
- `Native/GUI/Prefabs/Information/HintTooltip.xml:18` —— 边框同步内容块；
- `Multiplayer/GUI/Prefabs/Lobby/Clan/Lobby.Clan.Roster.xml:122` —— **`ItemTemplate` 内**的 `DimensionSyncWidget Id="..."`，按 Id 相对路径同步祖先。**这条最关键**：它证明「模板内写 Id ＋ 相对路径同步」是官方写法（官方 541 个 ItemTemplate 里 135 个内部写了 Id）。

⇒ 现结构：行容器 `ChatRow` 下挂 `ChatRowBody`（高度由文本撑）＋ `DimensionSyncWidget`（`DimensionToSync="Vertical"`、`WidgetToCopyHeightFrom="..\ChatRowBody"`）。**金条与内容块做兄弟，不从父级同步**，避免成环。

### 17.3 顺带修掉 Lab 的一个静默缺口

`preview/preview_prefab_geometry.py` 的 `_sync_size()` 原来把**未同步的那一轴一律当 0**。于是 `DimensionToSync="Vertical"` 的控件宽度恒为 0 ⇒ **几何上直接隐形，且不报任何错**（97 个控件只落 94 个）。

官方写法证明这是错的：`HintTooltip.xml:18` 是 `DimensionToSync="Horizontal"` 配 `SuggestedHeight="12"`；`GameMenu.xml:73` 是 `DimensionToSync="Vertical"` 配 `WidthSizePolicy="StretchToParent"`——**未同步轴走自身策略**。

⇒ 新增 `_own_extent()`，未同步轴按自身 Fixed／StretchToParent／CoverChildren 取值。
⚠️ 该改动只对含 `DimensionSyncWidget` 的 Prefab 生效；改前 AWAKE 侧 0 处使用（现 1 处，即本页），**对其余 7 个面板是零影响**（已用快照逐项核对）。
