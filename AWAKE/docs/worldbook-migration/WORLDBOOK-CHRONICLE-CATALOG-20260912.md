## 三、帝国疆域扩展史要点（本轮补课结论，Max 令）

1. **鼎盛期疆域＝全卡拉迪亚**：「从北方的雪原到南方的沙漠，都臣服在它的鹰旗之下」「帝国原本是没有边境要守的」。
2. **十世纪危机＝大解体**：达鲁索斯被废黜并吊死 → 大空位 → 「瓦兰迪亚，斯特吉亚，库赛特，阿塞莱**全部独立了出去**」——四族此前均为帝国治下；「多出了漫长的防线，这是我们衰落的开始」。
3. **东部行省**：百年前军团东进所获（湖泊与草原），设城镇哨站；被兀尔浑乃特率诸族夺回。帝国贵族称「必复却暂不能复」；库赛特贵族称「祖辈传下的牧场」「把帝国人赶过了湖」——**双视角叙事完整**。
4. **南部城邦**：独立城邦 → 邀帝国介入 → 被条约与武力吞并 → 卡拉德贵族与当地通商巨豪/游牧酋长通婚同化（「你要说我们是帕拉人我们反倒跟你急」）→ 南帝国核心；支持拉盖娅。
5. **瓦兰迪亚**：三世纪前渡海（南部岛区→奥斯蒂港登陆）→ 雇佣兵 → 沃提俄斯皇帝起以地代饷 → 蚕食帝国城市 → 十世纪危机时戴·梅罗克家的奥斯里克独立 → 元老院送金冠承认 → 初始疆域「仅沙拉斯到奥斯蒂港沿海一线」。**沃提俄斯有官方 A 级旁证**（`pn79h0aj`「我们的头衔是沃提俄斯皇帝钦赐的」）。
6. **巴旦尼亚**：「砍伐我们的圣林」——**唯一从未被吞并的腹地文化**（圣林/森林之灵叙事）。
7. **中原**：帕拉人纪元前已开垦；帝国粮仓+兵源（军头多出中原：加里俄斯、克洛托耳）；民粹保守。

### 对「帝国名号」裁定的修订（接 19:16 讨论）

沙拉斯=第一殖民地+第一神庙+第一舰队+旧都（先于巴拉维诺斯）——帝国渗透最深，Charasea 曾是通名；**但编年史明言「如今沙拉斯还叫沙拉斯」**，帝国旧贵族今日的称呼是「**龙兴之地**」（编年史 Keywords 里已挂）。⇒ 结论收紧为：CN 译名「沙拉西亚」只作**历史叙述层词汇**（detail 层，帝国读书人语域），今日通用名=沙拉斯，旧贵族口头 epithet=龙兴之地。瓦尔切格（帝国从未统治）**禁用**此装置。
