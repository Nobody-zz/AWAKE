# 卡拉迪亚 · 文化原型与政体分层基准（2026-09-30）

> **本文用途**：世界书「政体/政治」类条目撰写时的**取材依据**。凡写政体件，先查本文。
>
> **两级依据，缺一不可**：
> - **① 历史原型**（甲方 2026-09-30 提供）→ 定**风味与说法**（NPC 嘴里的话像哪个世界）
> - **② 游戏政策**（`bannerlord.db` 实测）→ 定**机制与差异**（谁是统治者、谁支持、谁反对）
>
> ⚠️ **纪律**：原型是**启发来源，不是等同物**。写条目时**不用真实史名**
> （不写"凯尔特""蒙古""拜占庭"），用**卡拉迪亚自己的说法**。
> 原型的作用是让"风味"有根，不是给人贴标签。

## 一、甲方给定的原型对照（逐条 · 附官方描述文印证）

> 甲方原话（2026-09-30）：
> 「巴旦尼亚：凯尔特诸林间部落王国；斯特吉亚：基辅罗斯；库赛特：蒙古-突厥游牧汗国；
> 阿塞莱：深受绿洲商贸影响的前伊斯兰阿拉伯王国；
> 帝国：罗马-拜占庭（北：元老院为首的寡头共和制；南：地方贵族、王权为核心的拜占庭式君主制；
> 西：民粹主义倾向的军队强人政治）」

### 1.1 帝国 · `empire` —— 罗马-拜占庭

**甲方原型**：罗马-拜占庭；**北**=元老院为首的**寡头共和制**，**南**=地方贵族+王权为核心的**拜占庭式君主制**，**西**=**民粹主义倾向的军队强人政治**。

**官方描述文印证**（`spcultures.xml#empire.descriptionText`，官方中文原文）：

| 官方原句 | 对应原型要素 |
|---|---|
| 「所谓的"**卡拉德人没有君主**"」 | **罗马共和国**（王政废除后的无王传统） |
| 「对**自治之道**，以及在**保护个人自由和国家需求之间求得平衡**抱有强烈兴趣」 | 罗马**共和德性**（libertas / res publica） |
| 「一个有实无名的**君主政体**」 | 罗马→**元首制/拜占庭**的演变 |
| 「领袖不再是杰出的**民粹元老**，而是散布在大陆上的**大地主**」 | **元老阶层**被**大地主**取代 |
| 「军队的中坚力量不再是**公民步兵**，而是富人扈从们组成的**具装骑兵队**」 | **公民兵 → 具装骑兵（cataphract）**＝拜占庭军事形态 |

⇒ **「元老 vs 大地主 vs 具装骑兵」这三方，就是帝国政治角力的官方表述**。
**与 §1.1 的北/南/西三分可一一对应**（见 §三）。

### 1.2 阿塞莱 · `aserai` —— 前伊斯兰阿拉伯（绿洲商贸）

**甲方原型**：深受**绿洲商贸**影响的**前伊斯兰阿拉伯王国**。

**官方描述文印证**：

| 官方原句 | 对应原型要素 |
|---|---|
| 「分为数量繁多的**家族和分家族**，每个家族都有**详尽的族谱**」 | 阿拉伯**部落谱系制**（qabila / nasab） |
| 「统称为**巴努·阿塞拉**，也就是所谓**阿塞拉的子嗣们**」 | **部落祖先认同**（前伊斯兰的部落团结 asabiyya） |
| 「**民族意识**来自于追溯自己的血统至这位**传奇的族长**」 | 血统而非领土的**认同基础** |
| 「财富和力量，则来自于**对孤立水源的控制**」 | **绿洲水源控制**＝贸易命脉 |
| 「这些水源使得**远方的商队**得以穿越沙漠」 | **商队贸易**（caravan） |

⇒ **阿塞莱的政体底色**＝**部落谱系 + 商人豪门**。
**注意**：官方用「**苏丹**」作为统治者称谓，且 `defaultPolicyIds` 含
`policy_council_of_the_commons`（民众大会）—— **与"前伊斯兰部落议会"吻合**。

### 1.3 斯特吉亚 · `sturgia` —— 基辅罗斯

**甲方原型**：**基辅罗斯**。

**官方描述文印证**：

| 官方原句 | 对应原型要素 |
|---|---|
| 「**王公和波耶**们如今已将目光投向外部」 | **князь（王公）+ бояре（波耶）**＝基辅罗斯双阶层 |
| 「以其**战争般的经商方式和经商般的战争方式**为自己赢得声望」 | **瓦良格商团**（贸易与劫掠一体） |
| 「商人们冒险进入森林寻找**蜂蜜、沼铁还有毛皮**」 | 罗斯**毛皮贸易**（对拜占庭/东方） |
| 「吸引着来自海岸、草原和**诺德**的冒险者」 | **瓦良格人来自北方**（游戏里 `nord` 文化真实存在） |

⇒ **斯特吉亚的政体底色**＝**王公（大公）权威 vs 波耶贵族**。
**卡壳点**：统治者称谓是「**大公**」，`defaultPolicyIds` 含
`policy_lawspeakers`（述法者）+ `policy_precarial_land_tenure`（土地所有制）
⇒ **「王公有权号令波耶，但波耶握着土地」** —— 这就是它的张力。

### 1.4 库赛特 · `khuzait` —— 蒙古-突厥游牧汗国

**甲方原型**：**蒙古-突厥游牧汗国**。

**官方描述文印证**：

| 官方原句 | 对应原型要素 |
|---|---|
| 「兀儿浑大汗接受了草原边境**贸易城市**的投降」 | 草原政权与**定居城市**的关系 |
| 「他命令自己的**那颜**们放弃他们的**游牧生活**」 | **那颜（noyan）**＝蒙古贵族阶层 |
| 「他们得到了**封地**和建造堡垒的资金，并受鼓励把当地农民变成自己的**佃农**」 | **游牧→封建**的转型（封地+佃农） |
| 「然而，库赛特联盟的部落**仍然保留着许多游牧传统**」 | **转型未完成** |
| 「在半村半营的聚落里，**毡帐挨着泥砖塔**」 | 二元并存的**空间表达** |
| 「以那支在**两代人的时间**里把他们打造成一支军队的**部族**来命名」 | **部族联盟**（confederacy）由**核心部族**主导 |

⇒ ⭐ **这是六文化里最有价值的一条**：官方**明写了"游牧→定居"的过渡**
（那颜从游牧改封地佃农，但部落传统未消）。
**甲方第一轮说的「部落制 → 学者引入制度 → 改组为封建制」，在库赛特身上有官方原文托底。**

**库赛特的政策依据**：`policy_grazing_rights`（放牧权）+ `policy_sacred_majesty`（**君权神授**）
⇒ **「汗权天授 + 牧地共用」** —— 与突厥-蒙古的**腾格里授命**吻合。

### 1.5 瓦兰迪亚 · `vlandia` —— ✅ 甲方已给定：1066 年征服者威廉的诺曼底 / 英格兰

**甲方原型（2026-09-30 补）**：**诺曼底公国和英格兰的诺曼王朝**，参考 **1066 年「征服者」威廉入侵英格兰**。

**官方描述文印证**：

| 官方原句 | 对应原型要素 |
|---|---|
| 「第一批瓦兰迪亚人来自**海外**，他们是**雇佣兵和冒险家**，语言混杂」 | **诺曼人**（维京后裔在诺曼底立国，又跨海取英格兰） |
| 「帝国**雇佣他们保卫边疆**，抵御内陆尚未被征服的部落」 | **以雇佣兵身份起家**（诺曼人先为雇主打仗） |
| 「不久，**资金短缺**的帝国官员们开始用**土地补贴和头衔**来代替银币」 | **以地代饷** ⇒ 佣兵变领主（**诺曼领主受封诺曼底/英格兰**） |
| 「**重骑兵所向披靡**」 | **诺曼骑士**（1066 黑斯廷斯的重骑兵冲锋） |
| 「其传统吸取自**卡拉迪亚和他们遥远的故乡**」 | **混合文化**（诺曼=维京血统+法兰西语言+英格兰王权） |
| 「他们的名字取自于最早的一位**军阀**，"无畏的"维伦德」 | **军阀立国**（≈ 罗洛 / 威廉） |

**⭐ 最有力的官方印证**（与甲方「1066 威廉入侵」直接对应）：

> 引用 **`politics-succession` 条目 detail 档**（v35 已存在）：
> 「瓦兰迪亚的王位承袭自"**铁臂**"奥斯里克。**奥斯里克曾是一位军阀**，在他攻占了帝国的整个西海岸之后，
> 作为**议和的代价，帝国被迫承认他为国王**。他**分封自己的副官们为男爵和伯爵，授予他们对土地的宗主权**，
> 以换取他们在战争中为他效忠。有些瓦兰迪亚国王试图**扩张王权**；而另一些则**放任男爵们互相争斗**」

⇒ 这段**就是 1066 诺曼征服的卡拉迪亚版**：**军阀登陆 → 帝国被迫承认 → 分封副官为男爵伯爵 → 王权与男爵的长期拉锯**。
**「铁臂奥斯里克」= 征服者威廉的同构角色**（已经写进条目，不是我方新造）。

**政策依据**：`defaultPolicyIds` = `policy_feudal_inheritance`（**封建继承**）+ `policy_castle_charters`（**城堡地契**）。
`policy_feudal_inheritance` 官方说明：「拥有**严格正规继承法**的国家，**土地的封赏更难被废除**」
⇒ **这正是诺曼封建的核心诉求**（1066 后威廉要以世袭继承锁定征服成果）。

⇒ **瓦兰迪亚的政体底色**＝**征服者封建**：**一个外来军阀集团，靠分封锁定土地，与本土王权、男爵议会三方拉锯**。
**与 §四 `empire-system-vlandia-detail` 的官方原句咬合**：
「我们瓦兰迪亚的**男爵们几百年来都是这么打仗的**…**有继承规则，有国王和男爵之间写进誓言的效忠关系**」。
**与 `throne-paravenos` 的官方原句咬合**：「**谁掌控帕拉汶德，谁就掌控西部商路**」（男爵议会的权力基础）。

### 1.6 巴旦尼亚 · `battania` —— 凯尔特诸林间部落王国

**甲方原型**：**凯尔特诸林间部落王国**。

**官方描述文印证**：

| 官方原句 | 对应原型要素 |
|---|---|
| 「由巴旦尼亚的**诸部族**统治着，他们是这块大陆大部分地区的**原始居民**」 | 凯尔特**本土原住民**（被入侵者挤压到边缘） |
| 「位于**山顶的堡垒**见证了无数次抵抗**外来侵略者**的战争：起初是**帝国的军团**，最近是**斯特吉亚和瓦兰迪亚**」 | 凯尔特**山地堡垒**（hillfort）+ 抗罗马/抗盎格鲁 |
| 「精通**长弓、夜袭、林中闪击**」 | 凯尔特**游击与伏击**战法 |
| 「崇尚**勇武**精神，但**更喜欢糅合一点狡黠**」 | 凯尔特**英雄气概 + 诡计**（trickster 传统） |
| 「将一群牛赶入雾中的**偷牛人**」（cattle raid） | **牛群劫掠**＝凯尔特荣誉经济 |
| 「往敌方部落赴宴的**冠军勇士**…从包里拎出…**同族的头盖骨**」 | **部落仇杀与炫耀**（head-hunting） |

⇒ **巴旦尼亚的政体底色**＝**部落联盟 + 长老/至高王**，且**"勇武+狡黠"是它的文化签名**。
**政策依据**：`policy_cantons`（营房=部落编户）+ `policy_lawspeakers`（述法者/长老提法）
⇒ **「按家庭编户出兵 + 长老述法」** —— 与凯尔特的**部族-德鲁伊-法律传统**吻合。

## 三、三继承者的政体分层（甲方点名的重点）

> **甲方原型**：北=元老院为首的**寡头共和制**；南=地方贵族、王权为核心的**拜占庭式君主制**；
> 西=**民粹主义倾向的军队强人政治**。

**游戏侧铁证**（三个帝国**开局政策各不相同**，见 §四）：

| | 北帝国 `empire` | 南帝国 `empire_s` | 西帝国 `empire_w` |
|---|---|---|---|
| **甲方原型** | **寡头共和制** | **拜占庭式君主制** | **军队强人政治** |
| **开局政策** | `policy_feudal_inheritance` | `policy_royal_privilege` | `policy_land_grants_for_veterans` |
| **政策中文名** | 封建继承 | **皇室特权** | **老兵授田** |
| **统治者称谓** | 元老 | 元老 | 元老 |
| **统治者** | 卢孔 | 拉盖娅 | 加里俄斯 |
| **v35 正文原句** | 「**寡头政治倾向**的代表…只有**土地所有者**才可以接受教育…**元老院是至高无上的**」 | 「**政治就是私人领域的延伸**…让**皇位定于一尊**」 | 「**民粹主义倾向**的代表…以**土地犒赏老兵**…满是他的**士兵在强迫反对派噤声**的集会」 |
| **政策三方支持度** | 贵族 +0.75 / 平民 +0.65 | **统治者 +0.8** / 平民 **−0.75** | 平民 +0.5 / 统治者 −0.35 |
| **政治性格** | **元老院寡头** | **皇权独尊** | **军事民粹** |

⇒ ⭐ **三方对照完全咬合**：**甲方原型、开局政策、v35 正文，三者互证。**
**这是「政体不绑死」的最佳范例**：同一 `culture=empire`，三个王国**各带不同政策**。

**而 `culture=empire` 的默认政策只有 1 条**（`policy_senate`），
**其余 2 条都是王国层附加的** ⇒ **引擎结构本身就支持"同文化、不同政体"。**
