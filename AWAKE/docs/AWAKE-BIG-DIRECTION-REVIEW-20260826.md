## 审查结论

本轮讨论保留了正确的产品方向，但把长期愿景、首期闭环、未来领域、报告迁移、NPC后台行动和多阶段 AI 编排同时写进了同一条设计链。若直接据此开发，会造成首期范围膨胀、权威边界不清、Token/CPU 预算无法验收以及旧契约迁移被误认为已完成。

因此：

> **长期方向保留；首期技术含义必须收缩；未决边界不得继续被当作已确认架构。**

## 保留

1. AWAKE 是构建在 Bannerlord 上的 AI 原生模组，差异化是知识驱动的社会沙盒。
2. 自然语言负责表达意图；代码负责权限、结算、持久化和世界事实。
3. 世界事件、报道/季度报告、玩家知识和 NPC 认知保持独立。
4. NPC 的知识由身份、经历、渠道和来源产生差异，不共享全知视角。
5. Bannerlord 原版个人关系、家族关系和族长关系保留原有含义，不直接等同于信任、服从或说法可信度。

## 修订

1. **核心循环**：首期从“承载所有玩法的平台循环”收缩为“对话意图 → 知识处理 → 有限社交后果 → 事件记录 → 存档恢复”。
2. **输入提交**：需要正式的解析/预览、玩家确认、代码提交、结果表达协议，并区分角色扮演拒绝与系统取消。
3. **事件模型**：世界事件、领域效果、因果链和 Bannerlord 原版状态分开；当前事件记录不能独自承担完整世界因果内核。
4. **季度报告**：作为独立信息渠道重新立契约，明确发布、取得、阅读、权限和玩家知识写入；不直接复用七日 `weekly-report.v1`。
5. **NPC 知识**：权限、详细度、确定性、来源、表达意愿和行动相关性拆分；具体身份知识由内容包提供，核心只提供机制。
6. **关系与行动**：保留喜欢、相信、愿意透露、愿意服从、愿意承担风险的语义差异，但避免为所有 NPC 保存多套长期数值。
7. **记忆时间**：使用游戏内时间，区分接收、形成、强化和回忆；先定义记忆类型和最小字段，再定义衰减。
8. **AI 编排**：保留可插拔逻辑阶段，但由统一编排器按需调用；固定输入/输出契约和权限边界，不固定每次调用次数。

## 撤回

以下内容不再作为首期技术含义：

1. 当前就同时实现关系、经济、政治、战争、生活、创作和所有扩展玩法的平台承诺。
2. 每次交互固定经过前处理、检索、认知提案、回应和后处理五次 Provider 调用。
3. AI 主动生成世界事件作为首期核心能力。
4. 把农民、贵族、士兵、公证商人等具体知识范围硬编码在 AWAKE 核心。
5. 把“NPC 默认略偏愿意交流”作为所有 NPC 的统一行为规则；它只保留为避免无理由卡死玩家的体验目标。

## 暂缓

1. 季度报告迁移实现，等待游戏内季度日历、报告版本、旧存档和发布渠道契约。
2. NPC 自主行动与 T0–T3 后台调度，等待对话、知识、事件和存档闭环稳定。
3. 经济、政治、战争等完整领域模拟，等待统一命令、效果和因果边界验证。
4. 通用跨模组兼容平台，先定义有限适配接口和关闭时降级。
5. 内容包生态、成人扩展、玩家覆盖和冲突合并规则的全面实现。
6. 全局 Token/CPU 优化，首期先建立单场景预算和观测指标。
7. 复杂全世界传播、纠错和季度聚合，首期只验证直接对话产生的有限知识变化。
8. 玩家知识编辑、完整世界知识编辑和普通玩家的上帝视角调试。

## 首个推荐纵向闭环

```text
玩家用自然语言询问或传授一条与当前 NPC 身份相关的信息
→ 代码筛选知识权限和可见详细度
→ NPC 形成有限的听说/保留/相信判断
→ AI 生成符合身份和表达意愿的回答
→ 产生一次可观察的关系或短期记忆变化
→ 事件/认知结果写入存档
→ 读档后仍能恢复该结果
```

## 首期明确非目标

- 不实现完整经济、政治、战争和自主 NPC 世界模拟。
- 不实现季度报告迁移、全世界知识广播和 AI 自动生成世界事件。
- 不实现通用兼容所有大型模组的适配平台。
- 不实现所有 NPC 的长期记忆、复杂信任数值和逐人后台学习。
- 不把完整世界事实、NPC 隐藏知识或调试状态直接展示给普通玩家。

## 关键反问

1. 首个闭环是否只包含一次有限社交后果，还是必须包含玩家传授、NPC记忆和读档恢复的完整链路？
2. Bannerlord 原版状态、AWAKE 结构化状态、内容包事实和 AI 提案谁拥有最终读写权？
3. 当前事件契约只记录事实事件，还是另设统一 Command/Effect/Causation 作为领域结算权威？
4. 重大副作用的解析、预览、确认、提交、失败、取消和幂等协议是什么？
5. 一次同步交互最大 AI 调用次数、Token、延迟和降级上限是多少？
6. 玩家能看到哪些报告来源和不确定性，如何避免 UI 直接泄漏隐藏知识？
7. NPC 知识的权限、详细度、确定性、来源和表达意愿中，哪些持久保存，哪些即时计算？
