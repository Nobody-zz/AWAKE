本稿对"控件布局"改了四处
1. 补两栏：现稿只有「头带 + 模式 + 对话流 + 输入区」；本稿把 在场人物（列）与 说话人（卡）提出来，各占一栏。
2. 模式行重排：模式一/二靠左成组，历史挪到最右 —— 它是"离开当前对话"，与前两个不是一类。
3. 输入区补键：现稿只有「输入框 + 发送」；补出 结束，并把 状态说明行 放到输入框正下方。
4. 按钮状态补全：发送键有禁用态（空输入），模式键与条目都有明确的选中态（金框 + 金条 + 底色），不靠"变亮一点"。
待你定的两处：三栏是否瘦成两栏（480 的对话列是否够宽）；「此处」「立绘」两个图槽要不要保留。
