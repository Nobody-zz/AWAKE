# AWAKE 版本路线图 v0.1.x - v0.9.x

> 日期：2026-08-15
> 状态：路线图草案，供后续 grill-me 分批锁定
> 依据：`PLAN-AwakeSplit-Batch1-20260815.md`、`AwakeSplit-ContentClassification-20260815.md`、`AwakeSplit-SplitScheme-20260815.md`

## 0. 版本线与当前基线

- AWAKE 作为独立运行时，从 v0.1.0 重新起算；当前仓库中的过渡态代码不计入新版本线。
- 内容包作为独立仓库/子模组，接入后从 0.2.x 起逐步对等。
- 版号只按“可玩性验收 + 双路径验证”推进，不按功能数量推进。
- 每版号结束前必须满足：构建 0 警告 0 错误、SdkSmoke PASS、本地化 OK、双模块哈希一致、游戏内验收项通过。

## 0.1 功能构想总览

| 功能域 | 内容 |
| --- | --- |

| 内容包基础 | 世界书、信件、事件、非情色 NPC 主动基础 |
| 女神人格支线 | 女神人格、神谕入口、祭坛/愿力、女神对话 UI/VM |
| 情色机制支线 | 发情周期、身体开发、俘虏/玩家被俘、情色事件、放纵月、性权力事件（独立内容包支线） |
| 世界模拟 | 周报/季报、世界事件、政令、NPC 主动行为、世界状态影响 |
| 记忆与关系 | 分级记忆、承诺账本、记忆点、秘闻传播、双通道好感、家族/亲族关系 |
| 内容系统 | 事件 JSON、世界书导入、内容包 manifest、校验与作者工具 |

| 性能 | 索引、缓存、RAG、批量读取、可观测 |
| 发布 | 双路径验收、崩溃清零、打包、文档、发行渠道 |

## 1. v0.1.x：AWAKE 运行时核心基线

**目标**：让 AWAKE 成为真正内容无关、可独立运行的 AI 世界运行时。

### v0.1.0 运行时骨架

- 内容包切割完成，AWAKE 编译不引用内容类型。
- ModId/DLL/namespace/owner/路由/存储/菜单/日志/本地化全部 AWAKE。
- 双仓库：AWAKE 运行时 + 内容包仓库。
- 运行时公开接口（persona 对话壳、菜单、命令、存储、生命周期、ContentPolicy、知识语料、路由）以 API 契约落地。
- 重新接入 NPC 深谈菜单（运行时通用入口），移除 native 回退崩溃路径。
- 验收：无内容包时进游戏无女神/祭坛，NPC 深谈可打开 AI 覆盖层，不崩。

### v0.1.1 存储与持久化

- 与 Marcus 框架联调 `Companion pipe`，确认 `awake.npc.memories` / `awake.event_meta` 可读写。
- 运行时存储迁移状态机落地，旧运行时数据可迁移到 `awake.*`。
- SdkSmoke 覆盖：存储读写、迁移 marker、重启对账、重复不重放。

### v0.1.2 运行时知识

- 通用知识语料机制：空 corpus 可加载，内容包注册自己的世界书。
- 本地倒排索引与缓存，规则/RAG 冲突保护，中文 n-gram 回退。
- 知识检索无命中时正常降级，不阻塞对话。

### v0.1.3 运行时配置与兼容

- `Awake` MCM 设置页与 copy-on-first-run 迁移。
- Companion route/profile 从旧运行时路由迁移到 `awake.route.*`。
- 旧档/旧模块引用兼容策略落地（owner 锚点 spike 结论执行）。

**0.1.x 退出条件**：无内容包可独立游玩基础 AI 对话；记忆/事件冷却可持久；不崩溃；双路径验证门全绿。

## 2. v0.2.x：内容包重连与对等

**目标**：内容包通过 AWAKE 公开接口接回基础内容，不含固定女神人格与情色机制。

### v0.2.0 内容包接入 + 女神对话修复

- 内容包注册世界书、信件、事件、NPC 主动基础。
- ContentPolicy 最小基线：Pure 与启用档位双路径。

### v0.2.1 内容包机制对等

- NPC 主动、营地事件、信件收件箱、事件链经内容包运行。
- 内容包独立 SdkSmoke，引用已构建 `Awake.dll`，不链接源码。

### v0.2.2 旧档与配置迁移

- 旧内容数据读取/镜像由内容包仓库处理。
- 旧 MCM、Companion route/profile 迁移验收。
- 有/无内容包双路径保存读档回归。

**0.2.x 退出条件**：基础内容包功能对等、旧档兼容、无内容包 AWAKE 仍独立可用；女神人格与发情/身体/俘虏等情色机制均不在本版接入。

## 2.1 情色机制支线（独立岔开）

- 发情周期、身体开发、俘虏/玩家被俘、情色事件、放纵月、性权力事件等作为独立内容包子线。
- 不在 v0.2.x 接入，也不依赖 v0.2.x 完成；内容包由独立仓库维护。
- 建议在 v0.4.x 关系/记忆稳定后单独启动，走独立 PLAN 与独立 `ContentTier` 门控。
- 该支线必须满足 18+ 硬校验、性别/身份视角分支、ContentPolicy 门控，且不能阻塞 AWAKE 纯净运行时。

## 2.2 女神人格支线（独立岔开）

- 女神人格、神谕入口、祭坛/愿力、女神对话 UI/VM、女神输出 schema、提示词变量集合、`prompt.registry.write` 权限作为独立内容包支线。
- 不在 v0.2.x 接入；不依赖情色机制支线，可与内容包基础并行开发。
- 建议在 v0.2.x 内容包基础稳定后单独启动，走独立 PLAN 与独立 `ContentTier` 门控。
- 该支线必须通过 AWAKE persona 对话壳接入，不绕过运行时公开接口。

## 3. v0.3.x：世界模拟

**目标**：AI 参与世界运转，不只是对话。

- 周报/季报/世界公告。
- 世界事件引擎数据化：条件、权重、冷却、链式后续、后果追踪。
- 政令/政策对繁荣、忠诚、治安、粮食的真实影响。
- NPC 主动行为由性格、关系、场合驱动。
- 世界事件可生成、可持久、可追踪。

**退出条件**：事件对世界数值有真实结算，周报可生成并读档回放。

## 4. v0.4.x：关系与记忆深度

**目标**：NPC 记得住、会遗忘、会传播、有独立人生。

- S/A/B/C 记忆分级、游戏时间遗忘、承诺账本。
- 记忆点沉淀、同类事件合并、性格影响恩怨。
- 关系轴（信任/爱意/敌意）机制化，隐藏双向好感。
- 秘闻/流言传播链，公开后果与复仇钩子。
- 家族、亲族、主从作为永久关系事实注入 AI。

**退出条件**：NPC 跨会话记忆可读回，承诺不丢失，流言能影响对话与事件。

## 5. v0.5.x：内容系统与工具

**目标**：内容与机制彻底解耦，内容包成为数据产品。

- 事件 JSON 数据驱动，388 条事件分批入库。
- 世界书四档（clean/dark/extreme/bloody）导入与检索。
- 内容包 manifest、校验、哈希、版本管理。
- 作者工具：事件/角色/世界书校验器，开发者面板。

**退出条件**：新增事件不需要改代码，只改 JSON；内容包校验与版本检查通过。

## 6. v0.6.x：体验完善

**目标**：从“能用”到“好看、好读、好用”。

- UI/UX：字体、布局、弹窗、事件 UI、对话界面。
- 媒体：立绘、语音、TTS、事件插图，AssetHandle 接入。
- 诊断：命中率、失败率、耗时、token、队列。
- 引导与可访问性：无现代伦理文本，但文案清晰。

**退出条件**：游戏内 UI 不重叠、字体可读、媒体可替换、诊断可导出。

## 7. v0.7.x：生态与跨模组

**目标**：AWAKE 成为可承载多个世界观的平台。

- 跨 Mod capability URI 与版本化能力探测。
- 外部人格/世界书/内容包注册 API 稳定。
- 第三方内容包示例与验收 fixture。
- 存档/版本兼容矩阵与迁移工具。

**退出条件**：至少两个内容包（内容包 + 测试包）可并行或切换运行。

## 8. v0.8.x：性能与可观测

**目标**：语料、记忆、对话在大规模下仍稳定。

- 倒排索引、缓存、RAG 分层与预算。
- 记忆检索索引，top-k 与字节预算。
- 批量状态读取，避免 tick 阻塞。
- 性能基准：查询耗时、缓存命中率、规则命中率。

**退出条件**：合成语料性能断言通过，无全量扫描路径。

## 9. v0.9.x：稳定与发布

**目标**：达到可公开发布的稳定版本。

- 全量游戏内回归：新档、旧档、无内容包、有内容包。
- 崩溃/卡死清单清零，异常降级可预期。
- 文档、打包、安装说明、发行渠道准备。
- 版本冻结与长期维护策略。

**退出条件**：发布候选通过完整验收清单，用户可安装即玩。

## 10. 跨版本横切项

- ContentPolicy 贯穿所有版本，不后置。
- 存储管道、权限、主线程派发作为运行时红线。
- 内容包任何功能不得绕过 AWAKE 公开接口。
- 每版号必须双路径（有/无内容包）验证。
