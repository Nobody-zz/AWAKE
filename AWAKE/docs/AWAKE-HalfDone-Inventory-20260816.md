## 3. 重复/需要合并的部分

| 现状 | 问题 | 合并方向 |
| --- | --- | --- |
| 原版对话 UI | 保留 | 原版对话机制和 UI 永远保留，不替换、不接管 |
| `NpcDialogueOverlay` | 场景/面谈 AI 对话覆盖层 | 保留并继续打磨，作为贴近原版对话的 AI 覆盖层 |
| `AwakeMessengerOverlay` | 通讯录/来信/远程消息 | 负责联系人、写信、来信、历史，不替代场景内对话 |
| 通讯录深谈、场景 T/Y、遭遇面谈 | 三个入口 | 入口保留，但明确各自的会话形态：场景/面谈用 AI 覆盖层，远程用通讯录 |
| 将来“写信面板”与“通讯录写信” | 容易重复 | 写信直接内嵌通讯录会话，不做独立面板 |
| 将来“收件箱”与“通讯录未读” | 容易重复 | 来信挂在联系人会话上，不做独立收件箱 |

### 对话 UI 边界

- 原版对话 UI：不可动，永远是游戏原生对话入口。
- `NpcDialogueOverlay`：AWAKE 的场景/面谈 AI 对话覆盖层，保留并作为场景内 AI 对话主 UI。
- `AwakeMessengerOverlay`：通讯录/远程消息 UI，负责写信、来信、未读、历史。
- 两个 UI 不互相替代；后续只统一入口调度和视觉语言，不删除任一层。
