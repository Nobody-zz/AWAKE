## 三、09-16 已经定过的三件事（照抄，别重推）

出处：`docs/ANIMUSFORGE-LOCAL-MODEL-ANALYSIS-20260916.md` §8.4。

1. **`AWAKE.route.memory.daily` 切到 `ollama-local`**（本机 `qwen3:4b` 已装）。
   理由：**每日记忆归纳是结构化压缩**，不需要世界知识与文采 ⇒ **省 token，不动对话质量**，
   是四层里最安全的本地化对象。
2. **`AWAKE.route.npc.dialogue` 保持云端** —— 这条决定玩家感知质量，**不该为省钱先动**。
3. **先补 token 统计**：`Awake.log` 里 `token`／`Token` **0 命中** ⇒ 花了多少、花在哪条路由上**全是估的**。
   没有这个数，任何"省 token"的说法都无法验证。

> 原话（§8.4 末尾）：
> **「本地化的正确对象是辅助 LLM 调用，不是检索。我们该做的是开那个已经写好的开关，不是搬那 1.2 GB。」**

**为什么"不是检索"**：真机实测下一次对话 = **2 次云端调用**（`npc_dialogue_submit_accepted` 后约 9 秒跟一次 `memory.daily`）；
而**检索不花 token**（本地词法 ＋ 内存比对）⇒ 给检索上本地模型是**纯增支**（体积 ＋ 复杂度），不省钱。

## 四、本地小模型的实测边界（已经踩过，别再试错）

三条一手记录（`docs/AWAKE-Task-Queue-20260816.md:603 / :712 / :850`）：

| 做什么 | 结果 |
|---|---|
| **机械判定**（结构化 JSON 输出、局部 trait 判定） | ✅ **可用**。`qwen2.5:latest` 对 `http://127.0.0.1:11434/v1/chat/completions` 发真请求，**返回合法 JSON、解析通过**，回归里只留下目标 trait、无关项被正确剔除 |
| **自由文本语义抽取** | ❌ **不可靠**。`gpt-oss:20b` 中等批量 **180 秒超时、无本地提交**，批被暂停为 `in_doubt`；另一批低机械性门返 `ok` 但**漏 `content_hash`** ⇒ 云端校验拒绝、批暂停 `INVALID_MODEL_OUTPUT` |
| **文本扩写** | ⚠️ **会编**。返回可编辑散文，但**编造不支持的事实**（身高、战斗经历、信念、关系建议）⇒ 只能当创作辅助，**不是可信身份事实来源** |

⇒ **一句话判据：本地小模型放在"判"上可用，放在"写"上不可信。**
（与本项目另一条实证同源：**别拿模型的置信度当门禁阈值** —— 有模型答对率 0 而置信度 0.95。）
