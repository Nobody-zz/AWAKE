### 1.1 状态名（只许这五个）

`Default` / `Hovered` / `Pressed` / `Disabled` / `Selected`

- 逐状态出图，**不用 Brush 因子提亮**（会把材质颗粒一起提亮，读成蒙雾）
- **同一按钮四态的九宫格边距必须逐字节一致**，否则按下时内衬会跳
- `<Style>` 是部分覆盖 ⇒ `Extend*` 只在 `<Layers>` 写一次，状态里只覆盖 `Sprite`
- **焦点态复用 `Selected` 档**（见 §2.1）—— 不为焦点新增状态名

## 2 · 交互契约（「易用」那一半）

**总原则**：Gauntlet 本身有完整的焦点与手柄导航系统，原版和主流模组都在用。
新写的 Prefab 若不显式声明，等于**主动放弃键盘与手柄操作** —— 这不是引擎不支持，是没写。

### 2.1 焦点与手柄导航

每个可交互控件写三样东西，缺一样就漏一层：

| 属性 / 节点 | 写在 | 作用 |
| --- | --- | --- |
| `IsFocusable` | 控件本体 | 能否被焦点选中 |
| `NavigationScopeTargeter` | **同级的兄弟节点**（不是属性） | 声明 scope |
| `GamepadNavigationIndex` | 行 / 项 / 按钮 | 同 scope 内的选中顺序（0,1,2…） |
| `IsFocused` | 任意控件（只读） | 绑 `Selected` 态做高亮 |

- `ScopeMovements` ∈ `Vertical`（列表）/ `Horizontal`（横向按钮排）
- `ScopeParent` 是相对路径：`..\` ＝ 上一级容器，`..\.` ＝ 自己这一级
- ⚠️ **`GamepadNavigationIndex` 单独写不生效**，必须有同级 scope 托着
- ⚠️ **焦点可见态是必需品**：手柄玩家看不见鼠标，没有焦点态就是不能用。
  本项目状态名只许五个 ⇒ **用 `Selected` 档承载焦点**（`IsFocused` 绑过去），不新增状态名。

**照抄用的一手样例**（游戏原生）：
- 列表：`Native/GUI/Prefabs/GameMenu/GameMenuTroopSelection.xml`（`ScopeMovements="Vertical"` + 行内 `GamepadNavigationIndex`）
- 对话：`Native/GUI/Prefabs/Conversation/SPConversation.xml`

### 2.2 快捷键：复用原版类别，不自创

玩家对这套操作已有肌肉记忆，控件必须接上**游戏自己的** `GameKeyContext`：

| 动作 | 类别 | 键位 |
| --- | --- | --- |
| 关面板 / 返回 | `GenericPanelGameKeyCategory` | `Esc` / 手柄 `B`(RRight) |
| 确认 | 同上 | `Enter` / 小键盘 `Enter` / 手柄 `A`(RLeft) |
| 上一个页签 | 同上 | `Q` / 手柄 `LB` |
| 下一个页签 | 同上 | `E` / 手柄 `RB` |
| 对话继续 | `ConversationHotKeyCategory` | `空格` / `Enter` / 鼠标左键 / 手柄下 |
| 发送消息 | `ChatLogHotKeyCategory` | `Enter`（`FinalizeChat`） |

- **输入框「回车提交」是引擎自带的**：XML 上绑一行 `Command.TextEntered` 就有，不用写 C#。
  前提是 `RealText` 双向写回 VM（见 §2.5）。
- 键位显示文本用 `HyperlinkTexts.GetKeyHyperlinkText(...)`，可随玩家改键自动变。

### 2.3 最小点击区

| 控件 | 视觉尺寸 | 命中区 | 判定 |
| --- | --- | --- | --- |
| 关闭键 | 40×40 | 40×40 | ✅ 达标 |
| 主 / 次按钮 | 110 / 100 ×35 | 同视觉 | ✅ 高 35 |
| 页签 | 105×35 | 同视觉 | ✅ |
| 小标记键 | 65×**25** | **扩到 65×35** | ⚠️ 高 25 偏小 |

- 依据：桌面端点击目标建议 **≥ 32×32**；手柄走焦点，不受此限。
- 小标记键的做法：**视觉高度保持 25**，纵向包一层透明 `ButtonWidget` 把命中区撑到 35。
- 未验：真机命中区未测（§5）。

### 2.4 反馈与状态可见性

- **悬停 / 按下**：逐状态出图；**禁用**因子提亮。
- **禁用态必须看得出被禁用**：亮度 ×0.90、去色 ×0.45、嵌线强度 ×0.45（当前主按钮/页签的实施值）。
- **危险动作**：色板里已有 `fill.danger #403028` 与印 `#5A1E14`，**本批未启用**。
  新增危险按钮时用这两个 token，不许临时调红。
- **状态可见性只支持正向 bool** —— Gauntlet 不支持取反或表达式（全 Modules 扫描取反命中 = 0）。
  ⇒ 空列表提示必须由 VM 提供**互补属性**（`HasContacts` / `IsContactsEmpty`），**且两边都要发通知**。
  ⇒ 计算属性（`=>` 表达式体）不会自动刷新。
- ⚠️ **VM「算好 + 发通知」≠ UI「已消费」**：属性齐了还要 `grep <属性名> GUI/Prefabs/*.xml` 确认有节点读它。

### 2.5 绑定纪律（本项目已踩过的）

| 规矩 | 后果 |
| --- | --- |
| 命令前缀是 `Command.` | 写 `Event.` **静默失效** |
| `Color` 必须 8 位 `#RRGGBBAA` | 10 位被引擎**静默丢弃**，控件渲染成全白（本项目已犯两次） |
| 输入框 `RealText` 必须**双向写回** | 否则回车静默无效、发送键永远是灰的 |
| 字号只用 6 档：`28 / 24 / 20 / 17 / 15 / 13` | 现状 10 档，阶梯失控 |
| **sprite 里绝不烤文字** | 中文字体全映射楷体，烤进去就没法改 |

- 中文字体塌陷：简中把所有字体映射到 `simkai`（楷体）⇒ **没有「衬线 vs 无衬线」这一维可用**，
  层级只能靠 **字号 / 颜色 / 装饰线 / 留白**。
- `Color` 是**逐通道相乘**的染色（不是覆盖）；`AlphaFactor` 叠在它之上是乘数。

## 4 · 按钮族收敛口径（现状问题）

**现状**：四个按钮族的「面」各走一路 —— 主按钮是冷灰铁 + 橄榄木、次按钮是黄铜、页签是石板、关闭键是暖红圆。
单看每个都能用，四个摆在一起读成**四套件**。

⇒ 「廉价感」的另一半来源不是单个控件糙，而是**族与族之间没有共同语言**。

**收敛口径（建议）**：

- **同族 ＝ 同底材 + 同金线线重 + 同切角**；差异**只允许**出现在面色调与线脚粗细上。
- 关闭键是四族里唯一带色相的底 —— 要么给它一个明确的语义出处（关闭 / 危险），要么收回中性灰；
  **不能只是「红一点好看」**。
- 收敛顺序：关闭键 → 页签 → 次按钮（主按钮正在返工，见 §6）。

## 4.1 · 按钮族统一案 v1「一块料，三档火」（2026-09-15，**待甲方批准**）

### 三条口径

**一 · 一块料。** 全族同一个切角与端头曲线（`CUT = 13`，2026-09-14 定案）、
同一套框色（`FRAME_C = (58,51,42)` / `FRAME_LIT = (100,89,74)`）、同一受光方向（上/左）、
同一金线线重（2px）、同一材质颗粒（`delta=9, fine=0.9`）。
**框不再按族压暗** —— 旧的 `primary 66/58/47`、`secondary 48/42/35`、`tab 默认 54/47/39` 取消。

**二 · 三档火。** 差异只允许出现在「面」的**明度**与**火候**上，且必须单调：

| 档 | 明度 r | 火候 t | 面色 | 用在哪 |
| --- | --- | --- | --- | --- |
| 重 | 76 | 1.00 | `(76,66,46)` | 主按钮 默认 / 页签 选中 |
| 常 | 64 | 0.50 | `(64,57,44)` | 次按钮 默认 |
| 静 | 50 | 0.00 | `(50,46,39)` | 页签 未选中 |

- 火候 t 在**暖端 `(1.000,0.868,0.605)` ↔ 冷端 `(1.000,0.920,0.780)`** 之间插值（色相比），
  ⇒ 越重越暖、越静越冷，读起来是**同一块料的不同火候**，不是四种材料。
- 逐状态只在**同档内升降明度**，火候不动：
  主 `76/94/58`、次 `64/79/51`、页签 `50/63/42`。
- 禁用＝常档明度去饱和 10%。

**三 · 圆印留、但归队。** 关闭键保留圆印形制，并给 §4 质疑的红一个**语义出处：火漆印**
（AWAKE 是写信与对话的信件界面，火漆是这类物件本来就有的东西）。
但石圈受光由 `(140,132,115)` 收到 `(126,114,95)`、圈底＝框底 `(58,51,42)`、
金叉线重 `3 → 2`（＝全族金线线重）、火漆红只留在最里层且内径由 `5 → 5`（不放大）。
⇒ 它是这套料上盖的一枚印，不是第四种材料。

**四 · 选中页签不再只靠一根亮条。** 面**升到「重」档** ＋ 底部 **2px 金线** ＋ 其下 **1px 压深线**
（与碑面金规线同一语汇），替代原来"暗面上浮一根满亮度金条"的做法。
