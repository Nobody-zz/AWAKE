## 二、PoC2：武器/甲 XML 提取通道 ✅

**立住的通道**：`Modules/SandBoxCore/ModuleData/items/` 7 个 XML（weapons/body/head/shields/shoulder/leg/arm_armors）→ ElementTree 提取 Item 类（非 mp_）→ 组件属性转录（Weapon/Armor）→ DB localization join 官方中文名（token `wfhHGTbl` 式短 id）→ L 规格档。

- XML 报告的可选项共约 **970 件**（weapons 73＋Crafted 260、body 246、head 256、shields 75 等），本批选品 10 件验证：草原战弓、劲弩、重型圆盾、奢华布面铁甲、轻型扎甲、闭面军阀盔、侧护覆板盔、鳞甲护肩、鳞甲靴、鳞甲军阀护腕（品类＝弓/弩/盾/身甲×2/盔×2/肩/腿/臂，文化域 6 个）。
- **快照转录**：每件一行属性段（穿刺/弹速/精准/身甲/护头/耐久…），L2 文案中的数值全部来自转录，可机器对账。
- **已知边界**：CraftedItem（260 件锻造武器，含各文明 T1–T6 军械主力）的属性挂在配件＋模板上，未做模拟器级计算——**列入 PoC3 候选**（需按 crafting_template 聚合或接运行时模拟）。价值字段 Item 类在 XML 中为空（由游戏内 modifier 决定），故本批文案以战斗属性成文而非基准价。
