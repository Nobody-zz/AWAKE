## 6. 本次踩到并已固化的三条

1. **不能用 `git add <目录>` 做整批收口** —— 它会把该目录下**未跟踪**的文件一起卷进来（本例 `AWAKE/docs` 下就有 560 个）。
   正解：`git add -u -- <路径>`（只同步已跟踪文件的改动与删除）＋ `git commit -F <msg> -- <路径>`。
2. **收口前必须先过编译闸门**，否则会把编不过的状态钉进历史。本例先跑 `dotnet build AWAKE.Tests -c Release`：0 错误。
3. **`core.autocrlf=true` 且仓库无 `.gitattributes`** ⇒ 提交时会刷屏 `LF will be replaced by CRLF` 警告（噪声，非错误）。
   这条与项目已记录的"裸字节摘要行尾敏感"是同一个根因，**尚未处理**。
