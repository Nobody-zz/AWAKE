# 恢复与回滚

Worldbook Studio 的 handoff 消费通过 receipt ledger 记录。遇到 `in_doubt`，先读取 receipt；确认结果未知时标记 `unknown`，确认未消费且允许重试时执行 `retry_consume`。重复请求使用同一 handoff 与 receipt，不创建第二条来源。

交付根目录外置 `rollback-pointer.json`，回滚命令为：

```powershell
pwsh -File .\tools\customer-delivery\rollback-customer.ps1 -BuildId <awake-customer-build-id>
```

回滚只切换已验证的历史构建指针，不覆盖历史目录或 ZIP。若指针损坏、当前指针哈希不匹配或目标包校验失败，脚本 fail closed。
