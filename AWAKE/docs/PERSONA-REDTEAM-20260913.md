# 角色卡规范 · 红队测试报告（对抗性审查）

- 日期：2026-09-13
- 性质：**红队测试 / 对抗性审查**。不是评审"规范写得对不对"，而是**把规范当靶子攻击**——证明它在执行中会反过来损害它自己宣称的目标。
- 靶子：`AUTHORING-GUIDELINES.zh-CN.md` v3（W1–W9 + M1–M7）＋ `audit-character-enhancement.ps1`（E1–E5）＋ `persona_scenario8_focused.ps1`（M7）
- 红队目标（Max 给定）：**人物反脸谱化**、**模型扮演自由化**
- 弹药：76 张真实卡全量语料 + 合成对抗卡。数据脚本：`.workbuddy/tmp/_redteam_persona_20260913.py`、`_redteam_synth_20260913.py`

---

## 0. 核心结论（一句话）

**规范没有错在方向，错在把手段当成了目标。**

"反金句、反模板、反脸谱"的立意是对的；但落到条款上，它把三件事做拧了：

1. **把"素材约束"滑成了"输出约束"**——开始规定"模型必须怎么说话"（M4 阶梯表态、M7 复读率），而不是"给模型什么样的素材"。**这是扮泈自由被掐死的根因。**
2. **把"机械可测"当成了"质量本身"**——于是"刚好过门"成了最优写作策略（数字压下限、塞关键词、打乱句首）。**反脸谱的手段，制造了新的脸谱。**
3. **把"不复读"当成了"像本人"**——模型不复读卡里的句子，也可能是在说**通用的空话**。规范防住了复读，却完全没测"人格保真度"。**自由了，角色没了。**

---

## 1. 实证：一张"零个性但 100% 合规"的卡，门禁放行

红队的标准杀招是**证明靶子可被完全满足，同时产出一个废物**。我合成了这张卡（`_redteam_synth_20260913.py`）：

> 三条样本，形式各异（开头分别是「有人拿先人的名分…」「（沉默良久）库房见底…」「他不肯低头…」），不套问答框，都含条件词与底线词；三轴齐备；破例描述非空。

**判定结果：PASS（E1–E5 全绿）。** 证据：硬底线词命中 ✓、条件词命中 ✓、问答框 0/3 ✓、条数 3 ✓。

而它的与全体 76 张真实卡的用词相似度是 **0.000**——**连"差异度"这把尺子都挑不出它**。

它是什么？**一个可以改名叫任何帝国贵族的通用模板。** 把"先人的名分"换成"族里的旧事"、换成"父辈的誓约"，全都成立。

> ### **一个灵魂，可以是任何一张卡。**
> 这张卡能无痕混进真实卡群，跑绿七道门禁，然后交付。**门禁测量的一切维度，都不是"这是不是一个特定的人"。**

## 2. 逐条攻击

### RT-1（头号）· 规范在测"不复读"，却把它当成"像本人"

| | |
|---|---|
| 条款 | M7 / W9 第 6 道：`anyReplyRepeatedSlogan=false` 且 `maxOverlapRatio < 0.30` |
| 攻击 | 这是**拿一个特定小模型（qwen2.5）的输出**去判卡的死活。换模型、换温度、换 prompt，结论就变。卡的质量本不应该是模型行为的函数。 |
| 更狠的一层 | 门禁要求"模型回复与卡内样本重叠 < 30%"。可**模型吸收卡里的语料，本就是扮演该角色的最自然方式**。写手为了过关，只能**故意把卡里的句子写得"跟任何回复都不像"**——也就是**故意写得不像这个角色会说的话**。 |
| 损害 | **双杀。** 对扮演自由化：惩罚了模型的正常行为，迫使素材与角色语言脱钩。对反脸谱化：**"不复读" ≠ "像本人"**。模型不复读，很可能只是退回通用腔调——**通用腔调才是最大的脸谱**。 |
| 修复方向 | 判据从"模型不复读"退回**静态可测**的"卡内可整句背诵的句子数 = 0"；8 场景自检**降级为观测报告**（回答"这条卡会不会被小模型复读"），不再当硬门。 |

### RT-2 · E3 是常开门：87% 通过，47 张仅靠单字「但/却/才」

| | |
|---|---|
| 条款 | E3 条件化：运行时文本命中任一 `condWords`（含单字 **但 / 却 / 才**） |
| 证据 | 命中 `condWords` 的卡 **66/76（≈87%）**；其中**仅靠单字弱词**通过 = **47 张**（亦剌塔儿、伊亚拉斯、俄洛斯、克洛托耳、加里加斯、卡拉多格… ） |
| 攻击 | 中文里"才/但/却"近乎必然出现。这道门不拦任何东西，只制造"我很严"的错觉。 |
| 损害 | 把"底线要被条件裹住"这个真实要求，稀释成了"文里出现过一个'才'字"。**质量信号被关键词劫持。** |
| 修复方向 | 删掉裸单字；E3 并入 E2b，改成**语义检查**——条件从句必须**作用在底线本身**（模式如"除非/一旦…（底线）…"），而不是散落全文的任意"才/但"。 |

### RT-3 · E2b 强制的「底线 ∩ 可让」= 规范禁止了"没有底线的人"

| | |
|---|---|
| 条款 | E2b：运行时文本须**同时**命中 `hardlineWords` 与 `condWords` |
| 证据 | 同时命中者仅 **15/76**；其余 **61 张被判 FAIL**（乌尔玻斯、伊拉、伯里康、卡拉多格、卢孔、墨速宜… ） |
| 攻击 | 这条等于宣布：**每个角色都必须"有底线、可谈判"**。那么——反复无常的、无原则的、铁板一块绝不谈的、殉道式的人物，全被机器判死。 |
| 损害 | **这是人格维度的脸谱化。** 规范把"有理性的谈判者"这一种人格，强加给了全部 76 个角色。而 M6 明令反脸谱——**规范自相矛盾**。 |
| 修复方向 | 三轴允许显式声明 `none`（无底线 / 不可谈判 / 无破例）作为**合法人格**；E2b 由 AND 改为 OR，或直接退出机械判定、交人工。 |

### RT-4 · 三张力轴是同一套心理学骨架，且 74/76 根本没填

| | |
|---|---|
| 条款 | M2：先填 `hardLine` / `negotiable` / `breachSwitch` 三轴，再写正文 |
| 证据 | 三轴**齐备的卡仅 2/76**，其余 74 张缺失或空。 |
| 攻击（两层） | **① 规范写了没执行**：M2 是强制前置，97% 的卡直接跳过——与 E5 绕过同源（"规则在"≠"规则在执行"）。**② 骨架本身是同一套**：它把"一个人"还原为"底线＋可让＋破例"。所有人都是"有底线、可商量、会破例"，**同一套人格模型**。一个疯的、痴的、狂的、无我的角色，塞不进这张表。 |
| 损害 | 用"理性谈判者"的模板去要求全体——正是 M6 要禁的事。而 74 张不填，恰恰说明**作者们不认这套骨架能描述他们的角色**。 |
| 修复方向 | 承认"三轴"是**一种可选建模法**，不是唯一解；给"不适用"留口子（见 RT-3）。 |

### RT-5 · M4 阶梯表态 = 把帝国式的圆滑，升格成了"真人节律"

| | |
|---|---|
| 条款 | M4：角色**必须**"先认诚意 → 再谈可商量 → 最后守底线"，"绝不让角色一口抛结论" |
| 攻击 | 这是**一种文化的话术**——帝国宫廷式的迂回。一个库赛特头人、一个诺德狂战士、一个阿塞莱商人，说话的节律根本不这样。规范把这个语用模子定义为"真人说话的自然节律"，**是文化脸谱**，且**直接规定模型该怎么说话**——这是掐死扮演自由的最直白一条。 |
| 损害 | 所有角色被同一个语用模子压过 → 撞脸；且模型的演出节奏被写死，只能"先礼后兵"。 |
| 修复方向 | M4 从"强制阶梯"改为"**禁止在样本里给出可背诵的结论句**"（管素材，不管演出）；明确允许"直来直去 / 掀桌 / 沉默拒答"的人格。 |

### RT-6 · E1 的数字封顶（3–6 条）成了多样性天花板

| | |
|---|---|
| 条款 | E1：`selfClaimExamples` 条数 3–6 |
| 证据 | 样本数=3 条的 **39 张**，=6 条的 **0 张**，>6 条的 **1 张**——**全卡在压下限**。 |
| 攻击 | "3–6"里的下限被当成了目标，凑够 3 条即止。样本越少，模型可吸收的角色语言越薄，越容易**退回通用腔调**——**反脸谱的手段，反而加剧脸谱**。 |
| 损害 | 多样性被一个数字封顶；信息量大的角色（统治者、多面人物）被迫删减。 |
| 修复方向 | 下限保留（防空），**上限取消或大幅放宽**；用"每条必须提供新维度"的**质量约束**替代数量上限。 |

### RT-7 · E5「异构」把多样性降维成了"开头不雷同"

| | |
|---|---|
| 条款 | E5：问答框占比 ≥50% 判 FAIL；开头 8 字雷同告警 |
| 证据 | 即便 E5 升级后，样本中仍含问答框骨架的占 **148/206（72%）**——判定写的是"形式"，病还在"结构"。 |
| 攻击 | 把开头打乱、把"如何回应"换成"（沉默片刻）他…"，就能过。**多样性沦为句法噪音。** 真正的脸谱是**同构**（同一处境、同一盘算、同一结论），不是同开头。 |
| 损害 | 测错了维度：机制拦的是"句式重复"，而脸谱的本质是"结构重复"。 |
| 修复方向 | E5 升级为**结构多样性**：同卡内多条样本的"对象 / 利害 / 处境"必须成组不同（用实体与名词分布度量），而非句首。 |

### RT-8 · M6 脱名测试没有机械落地——最像"反脸谱"的那条，恰恰没有尺子

| | |
|---|---|
| 条款 | M6：遮住姓名，凭口吻能否认出是谁；同王国角色必须互不相同 |
| 证据 | E1–E5 中**没有一项**测"遮名可识别"。撞脸代理指标：同王国组内两两 4-gram 平均 Jaccard **0.021**，跨王国 **0.015**——**两组接近**，说明"王国文化底色"在样本层几乎没拉开差距。 |
| 攻击 | 最贴近"反脸谱"目标的一条，是**唯一完全没有自动化落地**的一条，全靠人肉。 |
| 损害 | 给"合规但撞脸"留了大通道（见第 1 节那张合成卡）。 |
| 修复方向 | 把脱名测试落成**同王国两两样本的语义 / 名词重叠上限**；或引入**盲评**（遮名让人或模型辨认是谁）。 |

### RT-9（结构性）· 规范整体越界：从"约束素材"滑成"约束输出"

这是所有"损害扮演自由"条目的共同根因：

- **合法边界**：规范应当只规定"给模型什么样的素材"（事实、边界、口吻线索）。
- **越界**：M4（必须按阶梯说话）、M7（模型回复与卡的重叠率）都在规定**模型的输出**。
- **修复原则**：**素材层强约束，输出层零约束。** 卡负责"他是谁、他在意什么、他的底线在哪"；模型负责"这一次他怎么说"。

### RT-10（结构性）· "完成 = 门禁全绿"会奖励"最省事的合规"

- 门禁越多、越机械，"刚好过门"就成了最优策略——RT-2/3/4/6 的实测都在证明写手正在压下限。
- **修复原则**：机器门禁定位为**下限拦截**，不是质量认证；质量认定交**人工签收 + 盲评**，并给"意外性"留正向信号。

## 3. 修复建议汇总

**原则级（三条）**

1. **素材 / 输出分离**：规范只管"给模型什么"，不管"模型怎么回"。（治 RT-1、RT-5、RT-9）
2. **允许缺席**：人格可以有"没有底线 / 不可谈判 / 没有破例"——给 `none` 合法化。（治 RT-3、RT-4）
3. **语义 > 关键词，结构 > 句式**：删裸单字词表；多样性测"对象与处境"，不测"开头与词形"。（治 RT-2、RT-7）

**条款级（落地清单）**

| # | 条款 | 现状 | 建议 |
|---|---|---|---|
| 1 | M7 / W9#6 | 硬门：模型回复 overlap < 0.30 | 降为观测；静态判据改"卡内可背诵句 = 0" |
| 2 | E3 | 关键词（含单字 但/却/才） | 删除裸单字；并入 E2b，改语义检查 |
| 3 | E2b | AND（底线 ∩ 可让） | 改 OR，或退出机械判定；允许 `none` |
| 4 | M2 三轴 | 强制三元骨架 | 改为可选建模法；承认 74/76 未填的事实 |
| 5 | M4 阶梯 | 强制话术节奏 | 改为"禁可背诵结论句"；允许直给 / 掀桌 |
| 6 | E1 条数 | 3–6 硬窗 | 下限保留、上限放开；以"新维度"作质量约束 |
| 7 | E5 异构 | 开头 8 字 + 问答框占比 | 升级为结构（对象/利害/处境）多样性 |
| 8 | M6 脱名 | 无机械落地 | 落成同王国语义重叠上限 + 盲评 |

## 4. 边界与未验证

- 本报告是**对抗性审查**，不是整改决定。所有"建议"均为方向，具体条款改动需 Max 裁决后再落规范。
- 未跑 8 场景实测（需本机 Ollama）；RT-1 关于"模型退回通用腔调"的论断是**推断**，未附实测——**标记为待验证**。
- 相似度（Jaccard）是**代理指标**，衡量"用词重合"，本身就不是"人格保真度"的正确度量——这正是 RT-7 / RT-8 的论点，请勿把它当作反例的反驳。
