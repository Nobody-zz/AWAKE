10. **判"缺陷"之前，先问它违反了哪条产品语义。** 若该语义**项目从没定过**
    （典型：损坏恢复到底该"重建可用"还是"保历史可查"——两者都要，先要哪个？），
    **先报「语义未定」，不要直接判缺陷**。缺陷是对着语义判的；语义没定，判了也不算数。
11. **结论要能被别人重跑。** 关键实验附**可直接粘贴的重跑脚本** ＋ **阳性对照**
    （成功路径必须也能被同一个探针测出来）。**只报阴性、不做对照的读数，一律降级为"疑似"。**
