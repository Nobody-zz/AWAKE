## 0. 三层结论（先看这个）

1. **官方 UI 体系里几乎没有中世纪材质**——材质词汇就是「暗色石板 + 鎏金细线 + 纯白剪影」。⇒ 用羊皮纸/亚麻/封蜡做 UI = **与原版区分度最大**；但**没有官方先例可抄**，"做到什么程度不违和"要靠原创把握。
2. **游戏世界自己的材质有"身份语义"**——物品价格梯度：天鹅绒 575（最贵）＞ 亚麻布 245 ≈ 皮革 230 ≈ 陶器 210 ＞ 羊毛 22（最便宜）。**材料即阶层**：跟世界书「一个对象 × 六身份观感」内核天然共振。
3. **"中世纪材质"与"线框结构"不互斥**——Max 提的线框方向（参照 worldbook-studio/persona-workbench 的开发者文档观感）可作**信息骨架**，材质作**触点锚点**，二者混合是可行第三路（见 §3）。

## 1. 证据层

### 1.1 官方 UI 贴图里的材质先例（实测，一手）

对 `NativeSpriteData.xml`（1.40M）+ `SandBoxSpriteData.xml` 搜 `parchment|paper|scroll|linen|leather|wax`：

- **真·材质 sprite 只有 3 个**：`General\Icons\ShopIcons\linen_weavery_large/small`、`General\Mission\weaverylinen`——全是**生产设施图标**（亚麻织坊），不是面板材质
- `character_creation_scroll_gradient`——角色创建界面有**卷轴渐变**元素（官方在特定场合用过纸卷意象，但不作面板底）
- 其余 100+ 命中全是误伤（`mousescroll`/`scroller`/`scrollbar` 滚动条）

⇒ **官方 UI 从没把纸/布/蜡当过面板材料**；但游戏世界里这些材料无处不在（见 1.2）。**材质进 UI = 无例可循的原创区，也是最大区分度区。**

### 1.2 游戏世界的材质词汇（BannerlordSage 一手数据）

| 物品 ID | 官方译名 | 价值 | 阶层语义 |
|---|---|---|---|
| `velvet` | 天鹅绒 | 575 | **贵族**（最贵） |
| `linen` | 亚麻布 | 245 | 城市/商人/手工业 |
| `leather` | 皮革 | 230 | 武人/工匠 |
| `pottery` | 陶器 | 210 | 日常民用 |
| `wool` | 羊毛 | 22 | **村民**（最便宜） |

（`hardwood` 查询无此物品，跳过。）

⇒ **材质自带身份信号**：村民摸羊毛、贵族披天鹅绒。这个梯度正好可以映射六身份（villager/townsfolk/soldier/merchant/headman/noble）——**材料不是装饰，是叙事的**。

### 1.3 "线框结构"参考（Max 提及 worldbook-studio / persona-workbench）

两者本机形态＝代码/文档工具（无 HTML 前端），其观感＝**开发者文档式线框**：等宽字体、清晰信息块、细线分隔、零装饰。

作为 UI 方向的含义：**去材质化的信息骨架**——单色细线 + 留白 + 字重/字号分层，把信息本身推到前景。
与方向 A 的关系：**不互斥**。线框可做"容器"（面板/条目/分隔），材质可做"锚点"（封蜡按钮、刺绣标题、羊皮内容区）——见 §3 方向 C。

## 2.5 材质的实际用量（实测 · 回答"用起来会不会眼花"）

**问题**：上一节给的是**材质特写**（1024 特写里的针脚/纤维/划痕/字迹残影）。特写的信息密度铺到真实面板上、还要压文字，**必然吵**——"材质样本"与"实际观感"是两件事，本节把后者做出来。

**做法**：按真实 UI 尺度渲染 600×400 面板，压真实中文（`simkai`——游戏内简体中文 DefaultFont，实测 `NativeLanguages.xml` 确认），材质按三档用量铺，只统计**无文字空白区**的 stddev：

| 档 | 做法 | 空白区噪声 stddev | 判语 |
|---|---|---|---|
| ① 满版铺 | 材质原样铺满 + 文字 | **23.6** | **眼花**：纹理与文字同级竞争 |
| ② 淡化铺 | 材质降到 22% 幅度 | **7.4** | **最差解**：材质身份丢了，也没换来安静 |
| ③ 只做有边界的件 | 底只留低频起伏；材质只出现在标题带/封蜡按钮/蜡板输入区 | **4.4** | **底安静、件有料** |

**三条结论（反直觉的是第 3 条）**：

1. **"底"只用低频**：`GaussianBlur(radius ≥ 20)` 抹掉全部高频纹理，只留大尺度明暗不均（有材料感的呼吸）。底是为承载文字服务的，不是展示材质的地方。
2. **材质进"有边界的件"**：标题带、按钮、输入区、描边——凡有明确边界的地方都可以贴材质；**连续面（正文区）一律素净**。材质面积宜 ≤ 面板 15%。
3. **"淡化"是最差解，不是折中**：它同时失去"材质身份"和"安静"两个好处。⇒ **要么给足（做成件），要么不给（做成底）**，不要中间态。

**技术附带**：材质件与底色必须**同族**（色温接近），否则出现"贴了张纸条"的断层——首轮装配时标题带用浅色羊皮纸压暗，与深底断层，改为同族毛毡后消失。

**复现**：`tools/awake-art-lab/explore_ui_usage.py` → `out/explore/legibility/ui_usage_3ways.png`（另见 `explore_ui_legibility.py` 的六格初版）。

## 3. 三个组合方向

| 方向 | 构成 | 风味 | 风险 |
|---|---|---|---|
| **A1 全材质** | 羊皮纸内容区 + 刺绣边框 + 封蜡按钮 + 织毯标题 | 最足 | 与原版距离最大；九宫格工程最累；做不好像主题餐厅 |
| **A2 全线框** | 单色细线骨架 + 字重分层，材质为零 | 最"开发者"、最静 | 失去"中世纪"身份，跟原版倒是区分了但丢了世界书锚点 |
| **A3 混合（本线倾向）** | **线框骨架**（面板/条目/分隔）+ **材质锚点**（封蜡按钮、刺绣标题带、蜡板输入区） | 信息层冷静、触点有风味 | 平衡难——材质少了没味道，多了喧宾 |

**A3 的具体形态**：面板＝深羊毛毡底（或干脆线框留白）+ 细线框；标题＝刺绣边带一条；输入区＝蜡板木牍；关闭/发送＝封蜡；分隔＝麻绳或墨线。**信息的归信息，风味的归风味**——这也接得住 Max"线框观感也不错"的判断。

## 5. 工程约束（不变，任何方向都要过）

1. **九宫格**：四边可拉 ⇒ 纹理必须可平铺、四角留装饰区、中段无方向性图案
2. **染色图标**：功能图标照旧白剪影（引擎染色），材质不进图标
3. **AI 材质 → 代码骨架**：压暗到 UI 明度 + 阴刻/平版骨架，流程同 `explore_ai_pipeline.py` 已验证
4. **授权**：AI 生成物归属取决于模型服务条款，**分发前必须确认**（上轮已立案）
5. **无文字**：所有样本已按"不可读"口径生成，后续不引入文字层（中文字体塌陷问题照旧）
