# AWAKE 体验 / 上手 / 测试改进建议

> 日期：2026-08-16

## 玩家体验

### P0

- 首次运行向导：检测 Marcus、一键打开 AI 设置、生成默认配置。
- 每个操作都有即时反馈：成功/失败/被拦截原因。
- 对话等待时明确显示状态，超时可 Esc。
- 事件收件箱升级为列表 UI，支持未读标记。

### P1

- 周报独立浏览器。
- Messenger 未读计数、来信通知、写信/回信。
- NPC 主动聊天冷却与“改天”记忆，避免重复打扰。
- 对话等待动画、流式状态、取消提示。
- 存档/读档后状态可靠回读。

### P2

- TTS / 语音、头像、Messenger 群聊与媒体。

## 上手难度

### P0

- 游戏内首启引导：三步完成“检测 → 路由 → Provider”。
- MCM 状态直读，不要求玩家懂 Route ID。
- 安全默认值 + 预设。

### P1

- 命令台热键提示。
- MCM 帮助入口和错误说明。
- 世界书/事件缺失时给出“内容包未安装”的明确提示。

## 开发者测试便利性

### P0

- 开发者检查面板：路由、存储、记忆、事件、性能分区显示。
- 游戏内测试触发器：强制事件、强制深谈、重置冷却。
- 结构化日志：按功能域过滤。

### P1

- 存档/读档回归夹具。
- 测试世界书与事件 JSON 夹具。
- 开发者模式下的世界书热重载。

### P2

- 自动化游戏内回归入口。
- 一键导出诊断包。
