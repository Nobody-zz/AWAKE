# AWAKE 卡拉迪亚世界知识建设索引

版本：2026-08-23

用途：给世界书作者提供一份“卡拉迪亚需要写哪些世界知识”的生产目录。它不是完整世界观正文，也不是把参考资料直接复制进世界书；它是一张作者工作清单，用来判断哪些知识必须建立、哪些知识应该分层、哪些知识暂时只能作为参考。

---

## 一、先确定本项目采用的世界基础

### 1. 当前默认时代

本项目默认以《骑马与砍杀 II：霸主》当前时代、约 1084 年书签作为卡拉迪亚基础世界的工作层。

这意味着：

- 当前正在统治的国家、领主、城镇和文化，优先按霸主当前时代整理；
- 《战团》及其 1257 年前后国家、人物和历史，属于未来参考层，不自动写入当前正史；
- CK3 模组二创、扩展宗教、扩展事件和非原生神话，属于二创参考层，不自动视为卡拉迪亚事实；
- 官方资料之间出现矛盾时，由开发者或世界书主编做出项目内裁定；
- “来自游戏”不等于“无需判断”，原版游戏文本和系统之间也可能存在叙述冲突。

### 2. 参考资料的使用顺序

| 优先级 | 参考来源 | 用途 | 注意 |
| --- | --- | --- | --- |
| A | Bannerlord 本地游戏数据、文化、NPC、聚落、王国和兵种数据 | 确认对象存在、名称、文化、身份、地点、兵种和当前结构 | 这是硬事实底座，但不自动解释社会意义 |
| B | 《卡拉迪亚编年史》 | 整理当前卡拉迪亚的历史、人物背景、政治和文化叙述 | 作为主要叙事参考，仍需处理前后矛盾 |
| C | 《卡拉迪亚之王》资料提取 | 补充国家、文化、宗教、制度、事件、地点和军事资料 | 成人扩展或二创内容不能直接进入基础正史 |
| D | 开发者原创裁定 | 解决冲突、填补空白、建立项目独有逻辑 | 必须标记为开发者原创并经过审核 |
| E | CK3、战团未来、成人拓展、未核实素材 | 伏笔、可选内容、未来世界或独立扩展包 | 不得污染当前 1084 基础知识 |

### 3. 每条知识都要标记四个维度

作者写作时，不要只写正文，还要判断：

1. **它属于哪个领域**：政治、经济、文化、战争；
2. **它适用于哪个时期**：当前、历史、战争前后、长期存在或未确定；
3. **它属于什么范围**：本地、本国、跨国、贵族圈、军队、私人或秘密；
4. **哪些身份知道以及能说到多详细**。

## 二、优先级说明

### P0：没有它就无法正常理解世界

优先建立：国家、文化、主要聚落、统治结构、当前战争、基本宗教、阶层关系、粮食和税收、军队与兵种。

### P1：有它才能让 NPC 说话像这个世界的人

优先建立：地方习俗、荣誉观、婚姻和继承、商路、赎金、征兵、军粮、葬礼、节庆、对外族的称呼、酒馆传闻。

### P2：用于丰富剧情和长期扩展

包括：古代遗迹、冷门人物、失落王朝、地方怪谈、神秘宗教、详细家族谱系、非当前时代的未来知识。

### 每个主题的最低完成线

- P0 主题：至少有一条客观摘要、一个来源、三种身份表达；
- P1 主题：至少有一条事实、一个地方或阶层范围、两种身份表达；
- P2 主题：可以先写成参考或待审核，不要求立即进入当前正典。

## 三、政治知识索引

政治领域回答的是：**谁统治谁、凭什么统治、权力如何运转、冲突如何被解释。**

### P0-政治：国家与统治结构

| 索引条目 | 必须回答的问题 | 最低内容 |
| --- | --- | --- |
| `politics.world.order` | 卡拉迪亚当前有哪些主要国家和势力？ | 国家名称、文化、统治形式、主要敌友 |
| `politics.empire.fragmentation` | 帝国为何分裂？三方帝国各自声称什么？ | 公开原因、三方立场、普通人知道的说法 |
| `politics.kingdom.*.overview` | 每个王国靠什么维持统治？ | 统治者、核心领地、贵族集团、主要矛盾 |
| `politics.kingdom.*.ruler` | 当前统治者是谁？权力来自哪里？ | 公开身份、继承或夺权背景、政治口碑 |
| `politics.kingdom.*.clans` | 哪些家族支持、反对或依附统治者？ | 主要家族、利益关系、公开冲突 |
| `politics.kingdom.*.succession` | 继承规则是什么？谁可能继承？ | 法理、习俗、争议和秘密层 |
| `politics.kingdom.*.foreign_relations` | 与邻国为什么敌对或结盟？ | 领土、贸易、旧仇、婚姻、宗教或资源 |
| `politics.settlement.governance` | 城镇、城堡和村庄由谁管理？ | 领主、头人、官员、税收和治安职责 |
| `politics.noble_order` | 贵族之间如何称呼、结盟、报复和互相约束？ | 礼法、声望、婚姻、封臣关系 |
| `politics.commoner_authority` | 平民向谁纳税、求助或申诉？ | 村庄头人、城镇官员、领主、教会或商人 |

### P1-政治：制度与权力的日常表现

- 封臣对领主的义务；
- 领主对城镇和村庄的义务；
- 王国议会、贵族会议或派系协商；
- 宣战、停战、结盟和赔偿的公开说法；
- 继承、婚姻、嫁妆和土地转移；
- 俘虏、赎金、人质和政治婚姻；
- 叛乱、篡位、独立和投诚；
- 领主失势后家族、债务和土地如何处理；
- 城镇自治、商人利益与贵族权力的冲突；
- 平民如何看待“合法统治”和“强者统治”。

### P2-政治：秘密与剧情扩展

- 私生子、隐秘继承人和未公开婚姻；
- 贵族之间的秘密债务和把柄；
- 王室、教会、商会或军队的幕后联盟；
- 被删去的族谱、失落的王位宣称；
- 只有少数公证商人、赎金经纪人或酒馆老板知道的政治传闻。

### 政治表达分层

- 平民：知道税、征兵、治安、战争结果和公开传闻；
- 村庄/城镇头人：知道地方官员、领主要求、税粮和征兵细节；
- 公证商人/赎金经纪人/酒馆老板：知道跨地区人情、债务、赎金和流传中的贵族消息；
- 士兵：知道军令、征兵、军饷、军队移动和战争结果；
- 贵族：按年龄、管理经验、家族地位和实际经历增加政治细节；
- 贵族兵种：只在涉及贵族军队、军官、家族和战争的领域获得缩减后的贵族信息。

## 四、经济知识索引

经济领域回答的是：**人靠什么活着、东西如何流通、钱粮如何被抽走、战争由谁供养。**

### P0-经济：生存基础

| 索引条目 | 必须回答的问题 | 主要身份 |
| --- | --- | --- |
| `economy.food.production` | 各地主要生产什么粮食和牲畜？ | 平民、头人、商人 |
| `economy.settlement.resources` | 城镇、城堡和村庄依靠什么资源？ | 头人、商人、贵族 |
| `economy.taxation` | 谁收税，收什么，多久收一次？ | 平民、头人、贵族 |
| `economy.trade.routes` | 主要商路连接哪些地方？ | 商人、酒馆老板、赎金经纪人 |
| `economy.market_prices` | 哪些地方缺什么、贵什么、容易被囤积？ | 平民、商人 |
| `economy.crafts` | 哪些地方以铁器、木材、皮革、马匹或纺织品闻名？ | 工匠、商人、头人 |
| `economy.currency` | 使用什么货币，谁能铸币或收取税款？ | 商人、贵族、头人 |
| `economy.household_labor` | 农民、牧民、工匠和商人的日常劳动如何分配？ | 平民、头人 |

### P1-经济：国家与战争经济

- 军粮从哪里来，谁负责征集；
- 兵役、军饷、装备和马匹如何供应；
- 城镇税收与村庄产出的关系；
- 领主、商人、工坊和运输队之间的利益；
- 债务、抵押、欠税和财产没收；
- 赎金如何估算，谁会替人筹钱；
- 战争对粮价、人口、商路和工坊的影响；
- 劫掠、封锁、围城和断粮；
- 走私、黑市和战时涨价；
- 商人如何判断战争风险和护卫费用。

### P2-经济：少数人知道的账目

- 贵族家族的债务和抵押；
- 商会与领主的隐秘合同；
- 赎金经纪人掌握的人质价格；
- 领主私下囤粮、军费缺口和欠饷；
- 伪造货币、走私路线和腐败官员。

### 经济条目的特殊要求

经济知识尽量写出“谁承担代价”：

- 粮价上涨，对平民意味着少吃一顿饭；
- 军粮征集，对村庄意味着牲畜和余粮被拿走；
- 关税增加，对商人意味着商路改道；
- 围城，对城镇意味着存粮、疾病和黑市；
- 欠饷，对士兵意味着逃亡、抢掠或倒戈。

## 五、文化知识索引

文化领域回答的是：**人们如何理解尊严、亲属、神明、外族、婚姻、死亡和日常生活。**

### P0-文化：文化共同体

对每个主要文化至少建立：

- 自称和外部称呼；
- 语言或口音特征；
- 主要生活方式；
- 对土地、血统、军功或贸易的重视方式；
- 对邻近文化的常见称呼和偏见；
- 服饰、饮食、武器或建筑的公共印象；
- 公开宗教或信仰框架；
- 婚姻、继承、葬礼和成年礼的基本规则。

当前基础文化索引至少包括：

- 瓦兰迪亚；
- 巴旦尼亚；
- 斯特吉亚；
- 库赛特；
- 阿塞莱；
- 帝国体系，并区分北部、南部、西部帝国的政治处境和自我解释。

### P0-文化：宗教与神话

- 普通人认为世界由什么力量支配；
- 神明、圣人、祖先或自然力量如何被称呼；
- 祭司、传教者或宗教场所的社会作用；
- 婚姻、出生、战争、疾病、死亡时的仪式；
- 什么被视为亵渎、污秽、背誓或不祥；
- 不同文化之间的信仰冲突如何表现；
- 平民实际遵守的习俗与贵族公开宣称的教义是否不同。

宗教条目必须区分：

- **客观制度**：有什么宗教组织或仪式；
- **信徒表达**：某人如何解释神意；
- **传说**：民间流传但未必为真；
- **秘密信仰**：少数人或异端团体知道。

### P1-文化：日常生活与社会礼法

- 饮食、酒、面包、肉、奶、盐和香料；
- 取名、称号、绰号和敬称；
- 婚姻谈判、嫁妆、贞洁和家族声誉；
- 收养、血缘、私生子和继承；
- 葬礼、墓地、遗体处理和哀悼期限；
- 节日、集市、婚礼、斗技和宗教仪式；
- 客人、乞丐、俘虏、异族和逃兵的待遇；
- 对誓言、荣誉、耻辱、复仇和报恩的理解；
- 贵族、商人、士兵和农民的说话方式；
- 村庄、酒馆、市场、城堡和军营中的禁忌。

### P2-文化：地方传说与身份记忆

- 古老英雄和建城传说；
- 某座山、河流、废墟或城堡的故事；
- 家族祖先、失踪者和复仇故事；
- 不同文化对同一场战争的不同记忆；
- 只有老人、祭司、酒馆老板或旅行者知道的地方传说。

## 六、战争知识索引

战争领域回答的是：**谁能打仗、为什么打、如何打、军队如何活下来、战争结束后谁付出代价。**

### P0-战争：军队与兵种

| 索引条目 | 必须回答的问题 |
| --- | --- |
| `war.army.structure` | 王国、领主、家族、雇佣兵和地方民兵如何组成军队？ |
| `war.recruitment` | 谁被征召，谁可以逃避，征兵由谁执行？ |
| `war.troop_roles` | 步兵、弓兵、骑兵、骑射手和攻城人员各做什么？ |
| `war.noble_troops` | 贵族兵种和普通征召兵有什么区别？ |
| `war.command` | 谁能发布军令，军官和普通士兵如何理解命令？ |
| `war.logistics` | 军粮、饮水、马匹、箭矢、武器和医疗从哪里来？ |
| `war.siege` | 围城、守城、投降、断粮和攻城器械如何被理解？ |
| `war.raiding` | 劫掠和正式战争有什么区别，谁承担后果？ |
| `war.mercenaries` | 佣兵如何招募、收费、换主和处理战败？ |

### P0-战争：当前战争与历史战争

每场重要战争至少建立：

- 战争双方；
- 公开起因；
- 更深层的政治或经济原因；
- 主要地点；
- 关键阶段；
- 对平民、商人、士兵和贵族的影响；
- 当前仍未解决的问题；
- 不同身份对战争的称呼；
- 哪些内容是事实，哪些是传闻，哪些是宣传。

### P1-战争：士兵知识

- 新兵和老兵的区别；
- 逃兵、俘虏、伤兵和阵亡者待遇；
- 军营纪律、惩罚和奖赏；
- 军饷拖欠、战利品和分赃；
- 不同文化军队的作战印象；
- 骑兵马匹、弓箭、盾牌和长矛的实际使用；
- 普通士兵对领主、军官和敌人的称呼；
- 士兵知道战术常识，但不自动知道战略机密。

### P1-战争：战后社会

- 伤兵和残废者如何生活；
- 村庄被征粮、征马或劫掠后的恢复；
- 战俘交换和赎金；
- 边境城镇的驻军和治安；
- 战败贵族的土地与家族处置；
- 战争记忆如何变成酒馆故事、军队传说或贵族宣传。

### P2-战争：秘密军事知识

- 尚未公开的行军路线；
- 真实兵力和军粮储备；
- 密令、间谍、叛徒和假情报；
- 某场战役中被隐瞒的失败；
- 只有高级贵族、军官或参与者知道的计划。

## 七、四领域之外的基础索引

四领域是世界书的一级分类，但以下对象是四领域共同依赖的基础资料，不能遗漏。

### 1. 地理与聚落

- 大陆、区域、山脉、河流和海岸；
- 王国边界与争议地区；
- 城镇、城堡、村庄及其隶属关系；
- 村庄向哪个城镇供应资源；
- 商路、军道、隘口和危险区域；
- 地方气候、农产、牧场和季节性风险。

### 2. 实体与关系

- 国家、王国和帝国分支；
- 家族、氏族和王朝；
- 领主、头人、商人、酒馆老板、赎金经纪人、公证人；
- 军队、兵种、佣兵团和宗教组织；
- 城镇、村庄、城堡、工坊和市场；
- 人物与人物、家族与国家、地点与资源之间的关系。

### 3. 时间线

- 当前时代的起点；
- 帝国分裂及其前因后果；
- 各王国近期战争；
- 当前统治者登位；
- 重要家族、战争和灾害；
- 战争前、战争中、战争后的知识版本；
- 未来参考层与当前层的隔离。

### 4. 名词与语言

- 国家和文化的自称、他称；
- 城镇、家族、人物和兵种的别名；
- 贵族称号、军职、官职和宗教称号；
- 普通平民会用的俗称；
- 侮辱、昵称、旧名和敌对称呼；
- 同一对象在不同文化中的不同叫法。

## 八、知识深度索引

作者不要一开始就为每个对象写完整百科。建议按深度生产：

| 深度 | 内容 | 适合身份 |
| --- | --- | --- |
| D0 | 名称、存在、所属文化或国家 | 几乎所有可接触者 |
| D1 | 公开摘要、地点、职业、基本关系 | 平民、旅行者、士兵 |
| D2 | 原因、制度、资源、战争经过和地方影响 | 头人、商人、士兵、普通贵族 |
| D3 | 多方利益、历史因果、家族关系、行政细节 | 经验丰富贵族、军官、专业中介 |
| D4 | 密令、隐藏动机、秘密债务、真实幕后关系 | 明确授权的少数角色 |
| D5 | 仅作者或审查者可见的未公开裁定 | 不进入普通 NPC 表达 |

注意：D4 和 D5 不是“写得越详细越好”，而是代表知道范围更窄。普通平民即使在对话中追问，也只能得到未知、传闻或推荐询问对象。

## 九、NPC 知识覆盖索引

| 身份 | 通常应该知道 | 通常不应该直接知道 |
| --- | --- | --- |
| 普通平民 | 本地粮价、税、征兵、习俗、传说、公开战争结果 | 贵族密谈、完整国家历史、战略计划、跨国政治细节 |
| 村庄头人 | 本村、本地区、本国税收、征粮、治安、领主要求 | 王室秘密、未公开继承、敌国高层计划 |
| 城镇头人 | 城镇行政、贸易、驻军、税收、商路和本国事务 | 绝密军令、贵族私人谈判 |
| 公证商人 | 契约、债务、商路、跨地区消息和公开贵族传闻 | 所有秘密；未经来源支持的幕后真相 |
| 赎金经纪人 | 俘虏、赎金、家族关系、债务和人质市场 | 完整军事战略、所有王室秘密 |
| 酒馆老板 | 旅行者消息、士兵传闻、地方人物、价格和流言 | 传闻背后的全部真实原因 |
| 普通士兵 | 战争常识、军营生活、兵种、军粮、参加过的战事 | 未参加战争的战略细节、贵族密令 |
| 贵族 | 家族、领地、国家政治、外交和管理事务，随年龄与管理能力增加 | 与本人无关的所有秘密；年轻低阶贵族不应全知 |
| 贵族军官/贵族兵种 | 贵族部分信息 + 军事相关知识 | 非军事领域的完整贵族政治秘密 |

这张表是默认画像，不是绝对规则。人物经历、所在地点、实际职业、年龄、管理能力、参加过的事件和收到的玩家传授，都可以让知识范围发生有限变化。

## 十、每条知识应该怎样建立

### 推荐索引卡


### 最低合格条件

一条知识进入正式世界书前，至少满足：

- 能说清楚它记录的对象；
- 能区分事实和观点；
- 有来源或明确的开发者原创裁定；
- 有知识适用时期；
- 有领域和范围；
- 明确哪些身份知道；
- 至少有一个适合身份的表达；
- 没有把未来、二创或成人扩展内容误写成当前基础正史；
- 没有把 NPC 不应知道的细节放进公开摘要。

## 十一、推荐生产顺序

不要从冷门人物或华丽传说开始。推荐顺序如下：

### 第一批：世界骨架

1. 卡拉迪亚当前地图和主要区域；
2. 六个主要文化与三方帝国；
3. 主要王国和统治者；
4. 主要城镇、城堡和村庄关系；
5. 当前战争、敌对和联盟；
6. 基础宗教和文化习俗；
7. 粮食、税收、商路和军队基础。

### 第二批：NPC 能够实际谈论的知识

1. 平民本地生活；
2. 村庄和城镇头人的本国事务；
3. 商人、赎金经纪人和酒馆老板的中介知识；
4. 士兵的战争常识和军营生活；
5. 贵族按年龄、管理经验和家族地位的知识差异；
6. 不同文化对同一对象的称呼和偏见。

### 第三批：历史和事件

1. 帝国分裂；
2. 各王国近期战争；
3. 主要家族的继承和冲突；
4. 城镇和地区的历史；
5. 战争前后不同版本的知识；
6. 周报可以统一分发的结构化事件摘要。

### 第四批：扩展和秘密

1. 贵族密谈和秘密债务；
2. 真实战争动机；
3. 失落王朝和古代遗迹；
4. 地方传说、怪谈和宗教异端；
5. 成人拓展、未来层和其他世界观子包。

---

## 十二、哪些内容暂时不要写进当前基础正史

以下内容可以保留在参考目录或待审核目录，但不要未经裁定直接进入当前世界知识：

- 《战团》时期已经发生的国家变化；
- 1257 年及之后的历史结果；
- CK3 模组的通用宗教、神话和事件；
- 无法确认属于卡拉迪亚当前时代的地名、人物或王朝；
- 与原版对象冲突但没有项目裁定的资料；
- 成人扩展包独有的政治、宗教和组织设定；
- 只存在于旧四版成人化世界书中的内容；
- AI 生成但没有来源或作者确认的事实；
- 只在单个 NPC 内心或个人经历中成立的内容。

这些内容不是永远不能使用，而是应该进入独立的未来、二创、成人扩展或待审核层。

---

## 十三、作者工作量的建议估算

第一阶段不建议追求“所有人物都有完整档案”。更合理的目标是：

- 8 个主要政治主体：三方帝国、瓦兰迪亚、巴旦尼亚、斯特吉亚、库赛特、阿塞莱；
- 每个主体 1 份政治概览、1 份文化概览、1 份经济概览、1 份军事概览；
- 主要城镇和核心城堡各 1 份地方档案；
- 每个文化至少 5 条 P0 文化知识；
- 主要战争或历史断裂至少 3 条 P0 历史知识；
- 每个领域先完成 10 条可供 NPC 对话使用的基础事实；
- 每条重点事实至少准备平民/中介/士兵或贵族中的两种表达。

这比一次性编写数百条零散百科更容易验证，也更容易让 NPC 立即表现出身份差异。

## 十四、最终检查问题

作者完成一批知识后，逐条回答：

1. 这条知识属于政治、经济、文化还是战争？
2. 它记录的是事实、传闻、观点还是秘密？
3. 它发生或适用于哪个时期？
4. 普通平民能知道多少？
5. 哪些身份应该知道更多？为什么？
6. 这个身份是通过什么途径知道的？
7. 这个人能说出完整细节，还是只能说摘要？
8. 有没有把未来层、二创层或成人扩展层混入当前正史？
9. 有没有把 NPC 观点误写成客观事实？
10. 如果 NPC 不知道，系统能否推荐真实存在的中介？
11. 这条知识是否能被事件、周报或玩家传授更新？
12. 删除这条知识后，世界骨架是否真的缺了一块？

如果第 12 个问题的答案是否定的，这条内容可能属于 P1/P2 扩展，不必阻塞 P0 基础建设。

## 十五、最重要的工作原则

```text
先建立世界骨架，再补地方生活；
先写客观事实，再写身份表达；
先分清当前时代，再处理未来和二创；
先限制 NPC 能知道什么，再考虑 AI 如何说得丰富；
先完成 P0 可用知识，再追求冷门细节和华丽传说。
```

这份索引的目标不是让世界书作者一次写完所有内容，而是让每一批新增知识都能放在正确的领域、时期、范围和身份层中，并且最终可以被 Studio、运行时和 NPC 知识调取机制一致理解。
