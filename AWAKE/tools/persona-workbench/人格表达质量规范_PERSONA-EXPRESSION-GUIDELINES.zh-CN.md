## 1. 硬门速查（`audit-character-enhancement.ps1`）

| 门 | 判定 | v4 关键变化 |
|---|---|---|
| E1 | 样本 3–8 条；rules+rbs ≥ 3 | 上限 6 → **8**（放宽，防卡下限写） |
| E2 | `tensionAxes` 三键皆非空（值可为 `none`） | 允许缺席；**但不得三轴全 none** |
| E2b | 底线词 **与条件词在 70 字窗口内共现**，或显式 none 且与条件共现 | 词表命中 → **窗口共现**（治"无条件绝对断言"） |
| E4 | `contradictionDescription` 非空（可写"无破例"） | 不变 |
| E5 | 结构框（`？——"` 或 `会/要+如何/怎样/怎么`）占样本 < 50% | **动词枚举 → 结构判定**；并扩查 `rules`（防搬家） |

词表（与脚本同源，改动必须同步两处）：

- 底线词：`绝不 绝不让 绝不容 绝不退 不容 宁可 宁死 断然 寸步不让 一石不让 一步不让 留不得`
- 条件词：`若 但凡 除非 一旦 只要 假如 万一 纵使 即便 容我 可以改 就算 宁可`
- none 声明：`无底线 无所固守 无不可让 什么都可让 并不固守 无不可舍 无一物不可让`

## 2. 观测速查（不判生死，出报告）

- **O1 复读自检**：`persona_scenario8_focused.ps1 -Cards <卡>` → 记录 `anyReplyRepeatedSlogan` / `maxOverlapRatio`。
- **O2 处境覆盖**：样本处境类 < 2 提示（**不是 FAIL**——误伤过合法角色）。
- **O3 族属符号**：单卡命中该王国族属符号 ≥ 4 提示。
- **O4 疑似纯台词**：样本引文占比 ≥ 0.7 提示。
- **O5 跨卡印章**：样本开头 8 字与 ≥3 张其它卡雷同提示。

## 3. 认证速查（人工，无自动化）

- **Q1 脱名辨认**：遮名 + 遮族属符号读样本 → 能唯一认出=过；只说出一类人=撞脸；完全认不出=空洞。
- **Q2 语义密度**：去专名重读 → 换成别人还成立=空洞；**至少两条"只有此人会说的话/做的事"**。
- 执行人不得与写卡同模型；结论留档。
