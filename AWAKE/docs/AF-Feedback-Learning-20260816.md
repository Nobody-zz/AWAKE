# AWAKE · AF 游戏内操作反馈学习

> 日期：2026-08-16

## 1. AF 的反馈特点

- 每个操作都有即时结果：成功、失败、被拦截、进行中。
- 颜色即语义：绿色成功、黄色提醒/等待、红色失败、浅色信息。
- 失败会说明原因，而不是静默。
- 长等待会明确告诉玩家“现在可以 Esc”。
- 大地图通知用快速信息，决策/错误用弹窗。

## 2. AWAKE 落地

新增 `AwakeFeedback`：

- `Show`：信息/成功/警告/错误
- `ShowSuccess` / `ShowWarning` / `ShowError`
- 颜色映射与 AF 语义一致

已接入：

- 命令台无法打开时显示黄色提醒
- NPC 主动接受显示绿色成功
- NPC 主动拒绝显示黄色提醒
- 长等待 Esc 提示已有本地化

## 3. 后续

- 事件结算、命令成功、存储失败逐步接入 `AwakeFeedback`
- 地图快速通知按需补充
