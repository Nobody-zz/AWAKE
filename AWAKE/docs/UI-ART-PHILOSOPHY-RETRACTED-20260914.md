## 一、不像中世纪 —— 而且问题不是「做得不够中世纪」

### 1.1 硬伤：我把项目自己写的禁忌画进去了

`UI-ART-STYLE-BASELINE-20260913.md` 第 85 行（禁忌列）原文：

> 禁：**齿轮**/分子/芯片/数据流；宜：抄本、印鉴、羊皮、拓片

我这一批交付了 **N-11 settings ＝ 一个八齿齿轮**。这不是「风格不够」，是**直接违反已写下的禁忌**。

### 1.2 我做出来的东西该怎么归类

既不是中世纪，也不是骑砍。它是**现代品牌规范手册／瑞士平面**：

| 我做的 | 真实出处 |
| --- | --- |
| 近黑底 ＋ 暖白字 ＋ 一道朱 | 现代深色 UI／品牌系统 |
| DM Mono 大字符距、套准角标、"SPECIMEN SHEET 01"、比例尺 | 瑞士平面／印刷工业／现代品牌规范 |
| 24 格、线宽恒定、方端 | 网格化现代主义。中世纪记号是**手写的**：有起笔收笔、有压感、有顿与收尖 |
| X／尖角箭头／齿轮／放大镜／圆环 i／三横 | Material·Feather 那一路的现代控件图标 |
| 楷体「恒形」 | 全版唯一沾点年代的地方 |

### 1.3 底色就是反的

羊皮纸是**亮的**（暖白、米黄、浅褐），铁胆墨是深褐，朱砂是红，金是金。
**暗底**是骑砍原版的语言，也是印刷时代之后／现代 UI 的产物 —— 但它**不是中世纪**。

## 二、宣言跟项目的想法不重叠

### 2.1 项目内核（引自项目文档，不是我编的）

- 世界书内核 ＝ **中立内核 ＋ 分层观感**：同一对象 × 六身份，「村民听到什么／商人知道什么／贵族看到什么」（`WORLDBOOK-ENCYCLOPEDIA-CHARTER`）
- 产品诉求 ＝ **「像和一个人持续相处」，不是翻数据库**（`AWAKE-ContactPanel-Concept`）
- 内容是**编年史**质感、禁现当代科学视角（硬规矩第 1 条）

### 2.2 我写的六段

形体恒定／材质是唯一的变量／留白承担重量／节奏靠间隔／色彩只有三四声部／要像一个人一刀一刀做出来的。

⇒ 能对上 2.1 里任何一条的：**零条**。
唯一勉强沾边的「同一副骨架换材质」，我也没把它说出来，只写成了一条通用材质守则。

### 2.3 根因（要记住的）

`canvas-design` 技能对本环节的要求是「**宣言要通用、像可以用在任何地方**」。**我照做了。**

⇒ **工具／技能的通用要求，不能压过项目的具体内核。**
⇒ 两者冲突时**以项目为准**，并且必须在交付里**显式说出这个取舍**，不能悄悄按工具的来。
