# AWAKE · 开发者测试工具

> 日期：2026-08-16

## 目标

在命令台“开发者检查”之外，提供游戏内测试触发器，减少重复进游戏操作。

## 功能

- 开发者检查
- 强制与附近 NPC 深谈
- 打开事件收件箱
- 打开世界周报
- 重置 NPC 主动聊天状态

## 实现

- `AwakeDeveloperTestActions`：统一测试动作。
- 命令台根菜单新增“开发者测试”入口，仅 `EnableDeveloperMenu` 开启时显示。
- 本地化中英文。

## 验证

- SdkSmoke：主动聊天重置路径可用。
- 游戏内：开发者菜单可打开测试工具。
